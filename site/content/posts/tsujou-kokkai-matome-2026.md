みんな「国会」って言葉は聞くけど、<strong>今の国会で何が決まったか知ってる？？</strong>😂

<strong>第221回通常国会の会期末が6月21日</strong>。あと2週間よ📋

## 霞ちゃんに<span class="mk">国会の現状</span>を聞いてみる📋

国会の動きはお堅いから、霞ちゃんに整理してもらうわ💕

{{< hukidashi who="kasumi" >}}
今国会、すなわち第221回通常国会は1月20日に召集され、6月21日に会期末を迎える予定であります。本日6月8日時点で残り2週間となりました。
{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}
通常国会って毎年やるやつだよね？？✨
{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}
ご明察です。憲法第52条に基づき毎年1月に召集される国会で、会期は150日間と定められております。今国会は予算審議と多数の重要法案が審議されました。
{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}
で、結局なに決まったの？？📋
{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}
ギャル庁で記事にした法案だけでも、国家情報局設置法・サイバー対処能力強化法・改正地域交通法・改正旅券法・改正民事訴訟法など、多岐にわたる法律が成立しております。
{{< /hukidashi >}}
