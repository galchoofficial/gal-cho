ちなみに高野山にはお寺が<strong>117ヶ寺</strong>あって、そのうち<strong>52ヶ寺が宿坊を備えてる</strong>とされてる🏨　だから「約50法人が宿坊をやってる」っていう報道の数字とだいたい一致するのよね。世界遺産って<a href="/posts/asuka-fujiwara-sekaiisan-2026/">奈良の飛鳥・藤原が登録勧告を受けた話</a>みたいに「登録されてやったー！」で終わりじゃなくて、そのあと人が来すぎて地元が対応に追われるフェーズが来るの。高野山はもうそっちに入ってるってこと👀

つまり<strong>「宗教法人だから非課税」</strong>っていうのは半分正解で半分不正解🙅‍♀️　お賽銭とかのお布施系は非課税だけど、宿坊（宿泊業）や駐車場経営、物品販売みたいな<strong>「収益事業」</strong>は普通に課税対象になるの📋⚠️

今回問題になったのは宿坊の収入。つまり<strong>「宗教活動」</strong>じゃなくて<strong>「ホテル業」</strong>の部分ってことよ🏨💸

### そもそも<span class="mk">なんで非課税</span>なの？🤔

ここ、一番ためになるとこだから丁寧にいくね。この仕組みが分かると<strong>宗教法人だけじゃなくてNPOとか学校法人のニュースも読めるようになる</strong>から得だよ✨

{{< hukidashi who="aashi" >}}そもそもさ、なんでお寺って税金払わなくていいの？ズルくない？？🤔{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}宗教法人は法人税法上「公益法人等」に位置づけられております。公益法人等については、収益事業から生じた所得に対してのみ法人税が課され、それ以外の所得には課税されないという扱いが定められています。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}え〜つまりどゆこと？？「儲ける商売の分だけ払え」ってこと？？{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}概ねその通りでございます。宗教活動そのものは利益を目的とするものではないとの前提に立ち、課税の対象外としつつ、営利企業と同じ市場で行う事業については同じ土俵に立たせるという趣旨と存じます。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}あ〜！お寺の隣のラーメン屋が税金払ってるのに、お寺のラーメン屋がタダだったらフェアじゃないもんね🍜　納得したわ{{< /hukidashi >}}

そう、ポイントは<strong>「宗教だから優遇」じゃなくて「同じ商売してるなら同じ条件で」</strong>っていう発想なの。だから宿坊もふつうの旅館と同じように課税されるってわけ💡

### 「収益事業」に<span class="mk">なる条件</span>は3つ📋

じゃあどこからが収益事業なの？っていうと、法人税法ではこの3つを全部満たしたときって決まってるの。

<div class="gov-block">
  <h3>📋 収益事業の3要件</h3>
  <div class="gov-row">

    <div class="gov-text">法人税法施行令第5条に<strong>列挙された34業種</strong>のどれかに当たること。物品販売業・不動産貸付業・飲食店業・駐車場業などが並んでいて、<strong>第15号が「旅館業」</strong></div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>2️⃣</small>継続性</div>
    <div class="gov-text"><strong>継続して</strong>行われていること（1回だけのバザーとかは基本外れる）</div>
  </div>
  <div class="gov-row">

    <div class="gov-text"><strong>事業場を設けて</strong>行われていること</div>
  </div>
  <div class="gov-conclusion">→ <strong>宿坊は「旅館業」＋「継続」＋「建物あり」で3つ全部クリア＝完全に収益事業</strong>🏨💸</div>
</div>

そして税率がこれ。ここも知られてないんだけど、<strong>収益事業でも普通の会社よりちょっと低い</strong>のよ👇

- 年800万円以下の部分：<strong>15%</strong>
- 年800万円を超える部分：<strong>19%</strong>（普通の会社は23.2%）

さらに<strong>「みなし寄附金」</strong>っていう仕組みもあって、収益事業で稼いだお金を宗教活動のほうに回した場合、<strong>収益事業の所得の20%を限度に経費（損金）として引ける</strong>の。

{{< hukidashi who="aashi" >}}待って、宿坊で稼いだお金をお堂の修理に回したら税金安くなるってこと？？めっちゃ良心的じゃん😳{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}収益事業に属する資産のうちから、収益事業以外の事業のために支出した金額を寄附金と「みなす」制度であります。宗教法人の場合、収益事業の所得金額の20％に相当する金額が損金算入の限度額とされています。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}じゃあ<strong>「ちゃんと申告して、ちゃんとお寺に使う」</strong>のがいちばん得なやつじゃん…なんで隠すのよ🫠{{< /hukidashi >}}

## 宿坊はどこから<span class="mk">旅館業</span>になるの？🏨

「え、参拝者を泊めるだけでも旅館業なの？お寺の善意じゃダメ？」って思うよね。ここ、国税庁の<strong>法人税基本通達</strong>にちゃんと線引きが書いてあるの。

{{< hukidashi who="kasumi" >}}法人税基本通達15-1-39において、宗教法人が宿泊施設を有し、信者又は参詣人を宿泊させて宿泊料を受ける行為は、15-1-42に該当するものを除き、旅館業に該当するものとされています。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}「15-1-42に該当するものを除き」…その42ってなに？？抜け道あるの？？👀{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}抜け道ではなく、低廉な宿泊施設に関する規定であります。次の要件を全て満たす宿泊施設の経営は旅館業に該当しないものとされています。{{< /hukidashi >}}

<div class="gov-block">
  <h3>🏨 旅館業に「ならない」ための条件（通達15-1-42）</h3>
  <div class="gov-row">
    <div class="gov-who"><small>🎯</small>目的</div>
    <div class="gov-text">その法人の<strong>主たる目的の事業を遂行するために必要な施設</strong>として設置したもの</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>🔗</small>利用</div>
    <div class="gov-text">利用が<strong>専らその事業の遂行に関連して</strong>なされるもの</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>🛏️</small>構造</div>
    <div class="gov-text"><strong>多人数で共用する構造・設備が主</strong>のもの（相部屋の合宿所みたいなイメージ）</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>💸</small>料金</div>
    <div class="gov-text">全ての利用者について<strong>1泊1,000円以下</strong>（食事を出す場合は<strong>2食付きで1,500円以下</strong>）</div>
  </div>
  <div class="gov-conclusion">→ <strong>上の4つを「全部」満たさないと旅館業扱い</strong>。1泊1,000円って条件がガチで厳しい😳</div>
</div>

つまり<strong>「1泊1,000円・2食付き1,500円以下の相部屋」</strong>ならセーフだけど、精進料理つきで個室、外国人観光客が予約サイトから取るような宿坊は<strong>どう見ても旅館業</strong>ってこと。

{{< hukidashi who="aashi" >}}1泊1,000円ってもう昭和の値段じゃん…今そんな宿坊ないでしょ😂{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}当該通達は実費程度の負担で宿泊させる施設を想定したものと存じます。宿泊料を対価として受け取り、継続的に一般の利用に供する形態であれば、旅館業に該当すると整理されます。{{< /hukidashi >}}

ちなみに宿泊ビジネスへの規制って宗教法人だけの話じゃなくて、<a href="/posts/minpaku-jourei-jisshitsu-kinshi-2026/">自治体が条例で民泊を実質禁止できるようになった話</a>みたいに、いま日本全体で「人を泊めてお金をもらう」ことのルールが締まってきてるフェーズなのよ🏠📋

## 1億円超の<span class="mk">申告漏れ</span>って？💰😱

報道によると、指摘された中身は「うっかり出し忘れた」タイプじゃなくて、もっとハッキリしたものだったの📋

<div class="gov-block">
  <h3>🔍 報じられている指摘の中身</h3>
  <div class="gov-row">
    <div class="gov-who"><small>🧾</small>共通する指摘</div>
    <div class="gov-text"><strong>住職側の私的な支出を宗教法人の経費に計上</strong>して、宿坊の所得を<strong>過少申告</strong>していたケースがあった</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>⛩️</small>総持院の例</div>
    <div class="gov-text">高野山真言宗の総本山・金剛峯寺の西隣にある総持院では、住職の家族が<strong>2022〜2024年の3年間</strong>に宿坊で得た収入などを私的に支出していたとされる</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>💼</small>その扱い</div>
    <div class="gov-text">国税局はこれを<strong>家族への給与とみなし</strong>、所得税の<strong>源泉徴収漏れ</strong>を指摘</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>✅</small>その後</div>
    <div class="gov-text">総持院は2026年9月13日までに、追徴となった税額を<strong>納付済み</strong>とコメントを発表</div>
  </div>
  <div class="gov-conclusion">→ <strong>「宿坊の収入を申告してなかった」より「経費に私的な支出を混ぜて所得を小さく見せた」</strong>という指摘の形なの📋</div>
</div>

ここ大事なんだけど、<strong>法人のお金を住職の家族が私的に使うと、税務上は「給与」になる</strong>の。給与になると会社（法人）側は源泉徴収して納めなきゃいけないから、それをやってないと<strong>源泉徴収漏れ</strong>として指摘される。税金の世界って<strong>「誰のお金か」「どういう性質のお金か」で扱いがガラッと変わる</strong>のよ💡（申告のしくみそのものが気になる子は<a href="/posts/kakutei-shinkoku-online-2026/">確定申告がオンライン化した話</a>もどうぞ）

{{< hukidashi who="aashi" >}}え、お寺のお財布と住職のお財布って別なの？家族経営っぽいイメージあったけど🤔{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}宗教法人は法人格を有する別個の主体であります。法人の資産を個人が私的に使用した場合は、原則として当該個人への給与等として取り扱われ、法人には源泉徴収義務が生じます。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}なるほど…「うちのお寺だからうちのお金」じゃないってことか。ここ勘違いしやすそう😳{{< /hukidashi >}}

## 過去にも<span class="mk">似た話</span>あったの？🔍

あったのよ。宗教法人の非課税枠が悪用された有名な例がこれ👇

2009年に問題になった<strong>宇宙真理学会</strong>のケースでは、休眠状態だった宗教法人を買い取った会社が、その名義でラブホテルを運営して<strong>宿泊料の一部を非課税の「お布施」として処理</strong>していたと報じられてる😨　ホテルの前に観音像を立てて、駐車場の壁に「喜捨をお願いします」って看板を出してたっていうから、なかなかの強引さなの。

これは<strong>「名義を借りて宗教法人の皮をかぶる」</strong>タイプで、今回の高野山の話とは性質がぜんぜん違う。でも共通してるのは<strong>「お布施にすれば非課税」という誤解（または悪用）が入り口になってる</strong>ってところなのよね📋

ちなみに宗教法人の数って、文化庁の宗教統計調査だと<strong>2014年の18万1,810法人から2023年は17万8,921法人</strong>へと、ゆるやかに減ってる📉　この「休眠法人」が売り買いされちゃうリスクは今もあるって言われてるの。

<div class="insight">
  <span class="insight-tag">💎 ぶっちゃけポイント</span>
  <p>宗教法人も<em class="kw">経営の時代</em>なのよ🤔⛩️　人口減少で檀家（信者）が減る→お布施が減る→経営が苦しくなる→宿坊やカフェで収益を上げる🏨☕　これ自体は悪いことじゃないの。むしろ<strong>「お寺を維持するための企業努力」</strong>よね✨　文化庁の統計でも宗教法人の数はじわじわ減ってるし、地方のお寺ほど厳しいって言われてる📉</p>
  <p>でも収益事業をやるなら、ちゃんと税金を払う必要がある。しかも前に書いたとおり<strong>税率は普通の会社より低いし、みなし寄附金で宗教活動に回した分は引ける</strong>。<em class="kw">制度はむしろ味方なのに、正しく使わないと敵になる</em>っていう構図なのよ📋⚖️</p>
  <p>観光でお金が入るようになった地域って、だいたい同じ課題にぶつかるの。<a href="/posts/niseko-machizukuri-jorei-2026/">人口5000人の町がまちづくり条例を全国で初めて作った話</a>とか、<a href="/posts/furusato-nouzei-jibasanpin-2026/">ふるさと納税の地場産品基準が厳しくなる話</a>もそう。<strong>お金が増えると、そのお金のルールを整える段階が必ず来る</strong>ってことなんだよね🏔️✨</p>
</div>

ルールを知らずにやっちゃうケースも、知ってて隠すケースもあるのよね😤　<strong>「神聖な場所」</strong>だからこそのイメージとのギャップに、あーしもちょっとビックリしたニュースだったわ⛩️💰

でもこれ読んだ人には<strong>「お寺だから非課税」じゃなくて「宗教活動は非課税、商売は課税」</strong>って正確に覚えて帰ってほしい。この一行だけで、次に同じニュースを見たときの解像度が変わるから🙏✨
