みんな覚えてる？？前にギャル庁で<a href="/posts/kokka-jouhou-kaigi-2026/"><strong>「好きな人を落とすための情報戦、個人戦よりチーム戦が強いよね」</strong>って例えて解説した法案</a>👀

あれ、<strong>2026年5月27日の参議院本会議でもう成立してた</strong>の！！🏛️✨

## おさらい：<span class="mk">何の法案</span>だっけ？🤔

正式名称は<strong>「国家情報会議設置法」</strong>（令和8年法律第28号）。2026年6月3日に公布されるよ📋

ざっくり言うと👇

今まで日本の情報機関って、外務省・防衛省・警察庁・公安調査庁がバラバラに情報を持ってたの。恋愛で言ったら<strong>友達がそれぞれ別々に「好きな人の情報」を持ってるのに共有してなかった</strong>状態🙅‍♀️

それを<strong>1か所にまとめる司令塔＝LINEグループの管理者</strong>を作るのがこの法律✨

で、ここ紛らわしいんだけど、<strong>「国家情報会議」と「国家情報局」は別物</strong>なのよ。名前が変わったわけじゃないの。難しいところは霞ちゃんに出てきてもらお👓

{{< hukidashi who="kasumi" >}}法律の名称は「国家情報会議設置法」であります。条文の第二条では、内閣に、重要情報活動及び外国情報活動への対処に関する重要事項を調査審議する機関として、国家情報会議を置くこととされています。そして附則による内閣法の改正により、会議の事務局となる「国家情報局」を内閣官房に設置することとされております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え〜つまりどゆこと？？？🤔　2個できるってこと？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}概ねその通りでございます。要約いたしますと、<strong>「国家情報会議」は閣僚が集まって方針を決める会議体</strong>、<strong>「国家情報局」はその事務を担い、各省庁の情報活動を総合調整する実働部隊</strong>、という関係と認識しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}あ〜、グループLINEでいうと<strong>「グループそのもの」</strong>が国家情報会議で、<strong>「管理者アカウント」</strong>が国家情報局ってこと？？💡{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}ご明察です。なお国家情報局の設置にあたっては、従来の内閣情報官及び内閣情報調査室を発展的に解消することとされております。ゼロから増えるのではなく、既存の組織を格上げ・再編する形であります。{{< /hukidashi >}}

## 前回の<span class="mk">心配な点</span>はどうなった？🤔

前回あーしが書いた「LINEグループの管理者が暴走したらどうする？」問題👇

結論から言うと、<strong>スッキリ解決はしてない</strong>の🫥

{{< hukidashi who="kasumi" >}}衆参両院の附帯決議には、政府の情報収集活動において個人情報やプライバシーが無用に侵害されることのないよう十分な配慮を求める旨、政治的中立性を損なう情報収集を行わない旨、特定の党派の利益または不利益を図るために国内の政治家や選挙区に関する情報収集を行わない旨などが盛り込まれたと承知しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}お、ちゃんと歯止めあるじゃん！！って思ったけど…それって法律の条文じゃなくて<strong>「附帯決議」</strong>なんだよね？？🤔　なんか違うの？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}重要な点であります。附帯決議は委員会の意思を示すものでありまして、<strong>法的拘束力を有しません</strong>。政府に対して尊重が期待されるにとどまる、と認識しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}えっ、つまり<strong>「守ってね（お願い）」</strong>ってことじゃん…😨　破ってもペナルティないやつ！？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}端的には、そのような性質のものであります。なお本法は行政機関相互の関係を律するいわゆる組織法であり、どのような情報活動が許されるのかを定める、いわゆる<strong>作用法は整備されておりません</strong>。この点が審議において最大の論点の一つとなりました。{{< /hukidashi >}}

## ぶっちゃけ<span class="mk">ポイント</span>💎

<div class="insight">
  <span class="insight-tag">💎 ぶっちゃけポイント</span>
  <p>法律が成立したからって、すぐ「日本版CIA」ができるわけじゃないのよ🤔</p>
  <p>これから<em class="kw">組織の設置準備・人員の確保・運用ルールの策定・既存の情報機関との連携体制の構築</em>…実際に動き始めるまでにはまだ時間がかかるの。でも<strong>「法律ができた」こと自体は大きな一歩</strong>よ✨</p>
  <p>あーしが今回いちばん引っかかったのは、<em class="kw">歯止めが「附帯決議」に寄ってる</em>ところ。附帯決議って要するに<strong>「お願い」</strong>なの。条文に書いてあれば違反は違法だけど、附帯決議は破っても直接のペナルティがない。この差、けっこうデカくない？😨</p>
  <p>あと<a href="/posts/bousaicho-secchi-houan-2026/">防災庁の設置法案</a>のときにも書いたけど、<strong>新しい役所ができるときは「権限」と「チェック」がセットになってるか</strong>を見るクセ、つけといた方がいいと思うの。権限だけ先にできるパターンがいちばん危ないのよ⚖️</p>
  <p>情報機関が強くなる背景には、<a href="/posts/mythos-ai-cyber-jouhou-2026/">AIを使ったサイバー攻撃</a>とか<a href="/posts/tokuryu-yamibaito-2026/">SNSで集まるトクリュウ型の犯罪</a>とか、国境をまたぐ新しい脅威が増えてるっていう現実もあるの。だから<strong>必要性そのものは分かる</strong>のよね。</p>
  <p>あーしは賛成とも反対とも言わないけど、<strong>この法律がどう運用されるか、あーしたちが見続けることが大事</strong>だと思うの👀 ギャル庁も引き続きウォッチするね🕵️</p>
