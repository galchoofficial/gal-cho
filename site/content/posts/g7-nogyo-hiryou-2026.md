これさぁ、「G7？？農業大臣？？関係なくない？？」って思うでしょ。<strong>めっちゃ関係あるから聞いて</strong>😤

G7（日本・アメリカ・イギリス・フランス・ドイツ・イタリア・カナダの7カ国）の農業大臣が集まって、<strong>「肥料が食料安全保障の重要課題だ」</strong>って認識を共有したの🌾📋

## そもそも肥料って<span class="mk">なに</span>が入ってるの？🌱

肥料の話をするときに絶対出てくるのが<strong>「肥料の三要素」</strong>。窒素（N）・リン酸（P）・カリ（K）の3つよ🌱

<div class="gov-block">
  <h3>🌱 肥料の三要素（N・P・K）</h3>
  <div class="gov-row">
    <div class="gov-who"><small>🍃</small>窒素（N）</div>
    <div class="gov-text">葉や茎を育てる。通称<strong>「葉肥（はごえ）」</strong></div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>🌸</small>リン酸（P）</div>
    <div class="gov-text">花や実のつきを良くする。通称<strong>「実肥（みごえ）」</strong></div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>🥕</small>カリ（K）</div>
    <div class="gov-text">根を丈夫にする。通称<strong>「根肥（ねごえ）」</strong></div>
  </div>
  <div class="gov-conclusion">→ この3つが揃わないと作物はちゃんと育たない🌾</div>
</div>

で、ここが本題なんだけど。日本で使われる化学肥料の主な原料<strong>「尿素」「りん安（りん酸アンモニウム）」「塩化加里（塩化カリウム）」は、ほぼ全量を輸入</strong>してるの🚢💦 農林水産省の資料だと、尿素はマレーシアと中国、りん安は中国、塩化加里はカナダが主な供給国よ。

しかもこの原料、<em class="kw">地球上の埋蔵地がめちゃくちゃ偏ってる</em>の。りん鉱石は中国・モロッコ・エジプトの3カ国で世界の経済埋蔵量の約8割、加里鉱石はカナダとベラルーシの2カ国に集中してるとされてる⛏️🌍

つまり<strong>「その国が売らない」って言ったら終わり</strong>。これが「肥料は安全保障の話」って言われる理由なのよ😨

## 肥料がなんで<span class="mk">問題</span>なの？🤔

農家がお米や野菜を作るには<strong>肥料が必要</strong>じゃん？？その肥料の原料をほとんど海外から買ってるから、世界で何か起きるたびに値段と量が揺れるの🚢

「なんで急に肥料の話になったの？」って思うけど、これ2021年からずっと続いてる話なのよ👇

## 政府はどうするつもりなの？霞ちゃんに<span class="mk">聞いてみた</span>📋

{{< hukidashi who="kasumi" >}}肥料を含む農業の環境負荷低減については、2021年5月に策定された「みどりの食料システム戦略」が基本となります。2050年までに化学肥料の使用量を30%低減するという目標が掲げられております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え〜つまり「肥料を減らす」ってこと？でも減らしたら作物育たなくならない？？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}単純な削減ではございません。2030年までは土壌診断による施肥の適正化、堆肥等の国内資源の利用拡大を進め、2030年以降は施肥のスマート化や、下水汚泥など国内資源からの高度な肥料成分の回収といった革新的技術の開発・導入を加えると整理されております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}あ〜なるほど！「無駄打ちをやめる」＋「国内にあるもので代替する」の二段構えってことね💡{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}ご明察です。加えて2022年12月27日に閣議決定された「食料安全保障強化政策大綱」では、2030年までに堆肥・下水汚泥資源の使用量を倍増させ、肥料の使用量（りんベース）に占める国内資源の利用割合を40%とする目標が示されております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}下水汚泥…？え、それ肥料になるの？？😳{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}国土交通省の資料によりますと、全国約2,000か所の下水処理場から年間約235万トンの下水汚泥が発生しておりますが、肥料として利用されているのは約14%にとどまると承知しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}えっ、残りの8割以上は肥料になってないってこと！？<strong>「捨ててたものを肥料に回せば輸入を減らせる」</strong>じゃん、それめっちゃ合理的✨{{< /hukidashi >}}

## 下水汚泥の肥料って<span class="mk">安全</span>なの？🚽🌾

ここ気になるよね。あーしも最初「え、大丈夫？」って思った😅

日本には肥料の中身と表示を規制する法律があって、2020年12月1日から名前が<strong>「肥料の品質の確保等に関する法律」</strong>に変わってるの（前は肥料取締法って呼ばれてた）📖

<div class="gov-block">
  <h3>📖 肥料の品質の確保等に関する法律（2020年12月施行）</h3>
  <div class="gov-row">
    <div class="gov-who"><small>🏷️</small>名称変更</div>
    <div class="gov-text">「肥料取締法」から改称。略して<strong>肥料法</strong>とも呼ばれる</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>🧪</small>配合規制の見直し</div>
    <div class="gov-text">品質が落ちない組み合わせなら<strong>配合しやすく</strong>なった</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>📒</small>原料管理制度</div>
    <div class="gov-text">原料の規格や帳簿の備付けが必要。<strong>虚偽宣伝は禁止</strong>（2021年12月施行）</div>
  </div>
  <div class="gov-conclusion">→ 国産肥料を広げるために<strong>ルールの側も整えてきてる</strong>🌾</div>
</div>

つまり「なんでも肥料って名乗っていい」わけじゃなくて、成分の規格と表示のルールがあるってこと。逆にいうと<em class="kw">法律の名前を変えてまで国内資源を使いたい</em>くらい、輸入依存がしんどいのよ💦

## あーしたちの<span class="mk">食卓</span>にどう影響？🍙

肥料が高い → 農家のコストが上がる → 農作物の値段が上がる → <strong>スーパーの野菜やお米が高くなる</strong>📈🥬

前にギャル庁で書いた<a href="/posts/tabemono-559hin-neage-6gatsu-2026/">「6月から559品目値上げ」</a>の記事の原因の一つがまさにこれなのよ👀 <a href="/posts/food-shohizei-zero-1percent-2026/">食品の消費税をどうするかの議論</a>も、元をたどればこの「食べ物が高すぎる」問題から来てるの💸

しかも肥料が足りないと → 農家が作付けを減らす → 食料の供給量が減る → <strong>食べ物が手に入りにくくなる可能性</strong>も😱🍙 <a href="/posts/surume-ika-tac-choka-2026/">スルメイカの漁獲上限の記事</a>でも書いたけど、「量が減る」問題は値段より先に食卓に来るのよ🦑
