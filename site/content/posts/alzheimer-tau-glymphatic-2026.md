## <span class="mk">グリンパティック系</span>ってなんなん？🧠

ここ、名前が難しすぎるのでかすみちゃんに原文役をやってもらうわね📋

{{< hukidashi who="aashi" >}}グリンパティック系ってさ、名前が強すぎて何も分からないんだけど…なにそれ？🤔{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}脳内において、老廃物を液体の流れによって洗い流すとされる仕組みを指す概念です。体の他の部位ではリンパ系がその役割を担っておりますが、脳では別の経路がその機能を果たしているとされております。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}え、つまり<strong>「脳の下水道」</strong>みたいなこと？？🚰 ゴミを水で流して外に出す感じ？{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}概ねその通りでございます。比喩として申し上げるなら、脳のゴミを水流で押し流すお掃除の経路、とご理解いただいて差し支えないものと存じます。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}で、今回の研究が注目したのが<strong>「アクアポリン4」</strong>ってやつなんだよね？これは何？🧐{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}脳内の洗浄システムにおいて、液体の流れを整える働きを持つとされるタンパク質であります。水の通り道を制御する役割を担っているとされております。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}あー、<strong>「水門」</strong>ってことね🚪 下水道の水の流れを整える門があって、そこがちゃんと開いてると掃除がはかどるってこと？{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}そのご理解で趣旨は通じるものと考えております。今回は、この経路の働きを薬剤によって高めることで、原因とされるタンパク質の蓄積が抑えられたと報告されております。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}なるほどね🧼 <strong>ゴミを拾いに行く</strong>んじゃなくて<strong>水門を開けて流れをよくする</strong>作戦ってこと。頭いい…✨{{< /hukidashi >}}

## ★でも<span class="mk">記憶の改善は確認できてない</span>📋

はい、ここが今回いちばん大事なところ。盛り上がってるところで水を差すけど、隠さずに書くのがギャル庁だと思うの✋

<strong>この投与によって、記憶や行動の面での改善までは確認できなかった</strong>の😥

つまり<strong>「脳のゴミは減った・脳の縮みは抑えられた」けど「その結果として記憶がよくなった」とは言えてない</strong>ってこと📋

{{< hukidashi who="aashi" >}}え、ゴミが減って脳も縮まなかったのに、記憶は良くならないってことある？？😳{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}今回の報告において、記憶や行動の面での改善は確認されなかったとされております。原因とされる物質の蓄積が抑えられることと、症状の改善が得られることは、必ずしも同一ではないと考えられております。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}そっか…<strong>原因を減らせても、壊れた神経が戻るわけじゃない</strong>って話に近いのかもね🥹{{< /hukidashi >}}

## そもそも<span class="mk">アルツハイマー病</span>って？🧠
