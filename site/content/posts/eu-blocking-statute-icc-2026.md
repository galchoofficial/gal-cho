## そもそも<span class="mk">ブロッキング規則</span>ってなに？🚫

ここからが制度の話。かすみちゃんと一緒にいくわ👓

{{< hukidashi who="aashi" >}}かすみちゃん、ブロッキング規則って名前からして強そうなんだけど、何をブロックするの？🚫{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}正式には<strong>規則2271/96</strong>と呼ばれるEUの法令であります。<strong>1996年</strong>に、キューバ・イラン・リビアに対する米国の域外制裁に対抗するために制定されました。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}域外制裁って何？アメリカの外にも効くってこと？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}そのような性質を指します。米国の制裁は、米国外の企業に対しても<strong>制裁対象と取引しないことを求める</strong>形を取ることがあります。この場合、EUの企業は二つの法に挟まれる状態となります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え、それって詰んでない？？アメリカに従ったらEU違反、EUに従ったらアメリカに怒られるじゃん💀{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}その板挟みの状況に対して、<strong>EUの法を優先せよ</strong>と定めたのがこの規則であります。具体的には、EU企業が対象の制裁に従うことを禁じ、その制裁に基づく外国判決の承認を拒否し、さらに生じた損害の賠償を認める仕組みとなっています。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}おお、「従うな」って法律で決めちゃうやつなんだ⚖️　でも今回のICCの話で、どうやって使うの？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}欧州委員会が、<strong>米国の対ICC制裁をこの規則の附属書に加える決定</strong>をすることで対象となります。その決定がなされれば、EU企業にとっては法的義務となります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}なるほど、リストに載せるかどうかの判断が残ってるってことか📋　そこがまだ決まってないのね🧐{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}ご明察です。{{< /hukidashi >}}

ただし注意点もあって、<strong>この規則はICCを制裁から直接守るものではない</strong>という指摘もあるのよ📌

守るのは<em class="kw">EUの企業や個人</em>だから、ICCという機関そのものへの制裁が消えるわけじゃないの🧐　「EU企業がアメリカの制裁に付き合わなくて済む」までが効果の範囲、って整理ね📋

あと<strong>2018年のイラン制裁のときに発動したけど効果は限定的だったと言われている</strong>のよ💭　企業からすると「EUに怒られるのとアメリカに怒られるの、どっちが怖い？」になっちゃうから、法律があっても現実が追いつかないことがあるの😣
