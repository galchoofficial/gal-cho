## そもそも<span class="mk">親権</span>ってなに？

ここ、めっちゃ大事なのに全員ふわっと分かってるフリしてるやつだと思う😂 霞ちゃんに硬いほうを言ってもらうわ。

{{< hukidashi who="kasumi" >}}親権とは、子を監護・教育する権利と義務、子の財産を管理する権利と義務、そして子を代理して法律上の行為を行う権限を含む概念であります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え〜つまりどゆこと？？？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}要約いたしますと、①子どもを育てること、②子どもの財産を管理すること、③子どもの代わりに契約などの手続をすること、この3つをまとめた権利と義務であります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}あ〜「育てる係」と「お金の管理係」と「ハンコ押す係」を全部ひとまとめにしたやつってこと？？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}ご明察です。そして2026年3月までは、父母が離婚する場合、その一方のみを親権者と定める必要がございました。いわゆる単独親権であります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}そこが変わったってこと？？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}概ねその通りでございます。2026年4月1日施行の改正民法により、協議離婚においては父母の協議で<strong>「双方又は一方」</strong>を親権者と定めることとされました。すなわち共同親権も選択肢となったものであります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}じゃあ話し合いがまとまらなかったら？？どっちも譲らないとかありそうじゃん😨{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}その場合は家庭裁判所が、父母双方の事情と<strong>「子の利益」</strong>の観点から判断いたします。民法第819条第7項により、共同で親権を行うことが子の利益を害すると認められるとき——身体的・精神的なDVや虐待のおそれがある場合などは、家庭裁判所は単独親権と定めることとされております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}そこはちゃんと逃げ道あるんだ…ちょっと安心した🥹{{< /hukidashi >}}

ちなみに家庭裁判所の手続き自体も最近どんどんデジタル化してて、離婚や養育費の請求が<a href="/posts/mints-saiban-online-2026/">オンラインでできる「mints」っていう仕組み</a>も始まってるの📱 制度と手続き、両方同時に変わってる時期なんだよね。

## なんで<span class="mk">変えた</span>の？

背景のひとつが<strong>養育費</strong>の問題なの💸

こども家庭庁が公表している令和3年度の全国ひとり親世帯等調査だと、<strong>20歳未満の子を養育している母子世帯の母のうち、養育費を「現在も受けている」と答えたのは28.1%</strong>。「過去に受けたことがある」が14.2%で、つまり<strong>7割以上が今は受け取れていない</strong>という結果だったの😨

## 共同親権でも<span class="mk">片方だけ</span>で決めていいこと

ここ、誤解が一番多いとこだと思う🙋‍♀️ 「共同親権になったら、いちいち元配偶者に連絡して許可取らなきゃいけないの？」って思うじゃん。でも違うの。

{{< hukidashi who="kasumi" >}}新民法第824条の2は、父母双方が親権者である場合であっても、<strong>「監護及び教育に関する日常の行為」</strong>については一方が単独で親権を行使できることを定めております。法務省のQ&A資料にも具体例が示されております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}具体例、気になるやつ👀{{< /hukidashi >}}

    <div class="gov-text">食事の準備、服を着せること</div>

    <div class="gov-text">習い事は通常は日常の行為。<strong>高校生が放課後にアルバイトをする場合</strong>も日常の行為にあたる</div>
  </div>
  <div class="gov-conclusion">→ <strong>一緒に暮らしてる親が、いちいち許可を取らなくていい範囲は広め</strong></div>
</div>

逆に<strong>共同で決める必要があること</strong>はこっち👇

- 入学・退学・転学・留学の手続き🏫
- 子どもの引っ越し（転居）🏠
- 生命に関わるような重大な医療行為🏥
- 子の氏（名字）の変更、養子縁組📝
- 長期間勤務する企業への就職の許可💼

つまり<strong>「今日どうするか」は片方だけ／「人生がガッと変わること」は2人で</strong>っていう線引きなの。意外とシンプルなんだよね。

しかも<strong>急迫の事情</strong>があるときは例外で、救急手術が必要なときとか、DV・虐待から逃れるための転居とかは、片方だけで判断できるようになってるの。これは大事なポイント💪

- 制度が始まったばかりで、そもそも<strong>情報が足りない</strong>📱

- DVや虐待があった場合は、そもそも<strong>単独親権のほうが適切</strong>🛡️

## で、あーしの<span class="mk">まとめ</span>

結婚そのものへの意識もここ数年でガッツリ変わってて、<a href="/posts/shussho-doukou-kekkon-ishiki-2026/">「一生結婚しない」が初めて2割を超えた調査</a>も出てるのよ💍 家族のかたちが多様になるほど、離婚したあとのルールも整えなきゃいけなくなるってことなんだと思う。

今回の数字で言えるのはこれだけ👇

- 2026年4月に両親が離婚した未成年の子は<strong>1万2,558人</strong>、うち<strong>24.7%が共同親権</strong>の対象📊
- <strong>母親の単独親権が8,454人（67.3%）</strong>で、まだ単独親権が多数派
- 共同親権でも<strong>日常の行為は片方だけで決められる</strong>（食事・習い事・短期の旅行・通常のワクチン接種など）📋
- 進学・引っ越し・重大な医療は<strong>共同で決める</strong>🏫
- 法定養育費は<strong>子1人あたり月2万円</strong>、先取特権は<strong>子1人あたり月8万円が上限</strong>💸
- ただしこれは<strong>施行初月・1カ月分の概数</strong>。傾向を断定できる段階ではない🙏

制度の話って「どっちが正しいか」で盛り上がりがちだけど、主役は親じゃなくて子どもなんだよね🥹 1カ月の数字にビビらず、これから何カ月分か積み上がったところをちゃんと見ていきたいわ📊✨
