みんな！！<a href="/posts/rinji-kokkai-shoushuu-shouhizei-2026/">食品消費税1%の審議</a>が進んでる臨時国会で、ついに本番が始まったのよ🏛️

<strong>10月13日（火）の午前9時</strong>、衆議院予算委員会で<em class="kw">全閣僚が出席する「基本的質疑」</em>がスタート📺

しかも<strong>午後1時</strong>からは<strong>日銀の植田和男総裁</strong>まで出席したの😳　これ、かなりの豪華回じゃん✨

## そもそも<span class="mk">予算委員会</span>ってなに？🤔

名前だけ聞くと「予算の話をする委員会」でしょって思うじゃん。でもぜんぜん違うのよ😂

<div class="gov-block">
  <h3>🏛️ 予算委員会がヤバい3つの理由</h3>
  <div class="gov-row">
    <div class="gov-who"><small>①</small>総理が出る</div>
    <div class="gov-text">他の委員会は<strong>担当大臣だけ</strong>。でも予算委は<strong>総理大臣に直接質問できる</strong>の🎤</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>②</small>テレビ中継</div>
    <div class="gov-text">生中継が入るから、<strong>全国民が見てる前</strong>での攻防になる📺</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>③</small>なんでも聞ける</div>
    <div class="gov-text">名前は「予算」だけど、<strong>予算に関係することなら実質なんでもアリ</strong>。だから内閣の問題点を追及する場になってる🔍</div>
  </div>
  <div class="gov-conclusion">→ つまり予算委員会は<strong>国会のメインイベント</strong>なのよ🏛️</div>
</div>

で、今回の初日は<strong>「基本的質疑」</strong>っていう形式だったの。ここ、かすみちゃんに硬く説明してもらうわ👓

{{< hukidashi who="aashi" >}}かすみちゃん、「基本的質疑」ってふつうの質疑とどう違うの？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}基本的質疑は、予算委員会の審議の冒頭に置かれる総括的な質疑を指す概念です。原則として総理大臣および全閣僚が出席し、内閣の基本方針や予算案の全体像について質疑が行われます。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え〜つまりどゆこと？？？大臣が全員そろってる回ってこと？😳{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}概ねその通りでございます。個別の分野に限定した質疑ではなく、横断的な論点を扱う回でありますため、閣僚全員の出席が求められるという整理になります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}てことは「どの大臣に何が飛んでくるか分かんない回」じゃん😂　緊張感えぐいわ💀{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}質疑者は事前に通告を行う慣行がございますが、答弁者が広く求められる点はご指摘のとおりと承知しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}金利が上がると、変動のローン組んでる人の返済額って増えちゃうんだよね？🥹{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}変動金利型の住宅ローンにつきましては、基準となる金利の変動に応じて適用金利が見直される仕組みであります。返済額の見直し時期や上限の取扱いは金融機関ごとの契約条件によりますので、個別の条件をご確認いただくのが適切と存じます。{{< /hukidashi >}}
