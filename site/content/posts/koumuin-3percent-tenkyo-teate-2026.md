これさぁ、「公務員の給料上がるの？いいなぁ」って思うかもしれないけど、ちゃんと理由があるから解説するね👀

人事院が2026年8月7日、国家公務員の月給を<strong>1万5,056円（3.51%）引き上げる</strong>よう国会と内閣に勧告したの💴📈 これで<em class="kw">2年連続の3%超</em>、しかも月給とボーナス両方がプラスなのは5年連続なんだって🎉

さらに<strong>「転居手当」</strong>っていう新しい手当も作るって話も入ってるのよ🏠✨

## 人事院勧告って何？📋

人事院っていう組織が「公務員の給料はこのくらいにすべき」って毎年政府と国会に勧告するの📋

これ、実は法律にちゃんと根っこがあるのよ。かすみに条文を出してもらうね👇

{{< hukidashi who="kasumi" >}}国家公務員法第28条は「情勢適応の原則」として、給与、勤務時間その他の勤務条件に関する基礎事項は、国会により社会一般の情勢に適応するように随時これを変更することができると定めております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え〜つまりどゆこと？？「社会一般の情勢に適応」ってふわっとしてるんだけど🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}要約いたしますと<strong>「世の中の給与水準が動いたら、公務員の給与もそれに合わせて動かす」</strong>という趣旨です。同条第2項では、人事院は毎年少なくとも1回、俸給表が適当であるかどうかについて国会及び内閣に同時に報告しなければならないとされています。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}<strong>「民間が上がったら公務員も上がる、下がったら下がる」</strong>ってことね！毎年チェックするのが人事院の義務ってことか💡 でも公務員って自分でストライキとかできないんじゃなかった？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}ご明察です。国家公務員は労働基本権が制約されており、その代償措置として人事院勧告の制度が置かれていると認識しております。なお、俸給表の給与を5%以上増減する必要が生じたと認められるときは、報告にあわせて適当な勧告をしなければならないとも定められています。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}あ〜！！<strong>「交渉できない代わりに、第三者が民間を調べて決める」</strong>仕組みなんだ。だから毎年8月に勧告が出てくるのね📅✨{{< /hukidashi >}}

## 「転居手当」って何がうれしいの？🏠

これ、地味だけどガチでデカい話なの。公務員の転勤って<em class="kw">引っ越し代が実質自腹になりがち</em>って言われてたのよ😥

## 地方公務員や民間にも<span class="mk">波及</span>するの？🌊

ここ勘違いしやすいから整理するね👇

{{< hukidashi who="kasumi" >}}人事院勧告は国家公務員を対象とするものであり、地方公務員の給与に自動的に適用されるものではありません。各地方公共団体では、それぞれの人事委員会の勧告等を踏まえて条例で定められると承知しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え、じゃあ学校の先生とか市役所の人は<strong>まだ確定じゃない</strong>ってこと？？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}その通りでございます。ただし国の勧告が各人事委員会の勧告の参考とされる関係にあり、実務上は同様の方向で検討される傾向があるとされています。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}<strong>「国が先に走って、地方があとから追う」</strong>感じか〜💡 だから「国家公務員が上がった」ってニュースは、地方の給料や民間の賃上げムードの<em class="kw">先行指標</em>として見るのが正しいのね✨{{< /hukidashi >}}

あと勧告はあくまで<strong>「勧告」</strong>だから、実際に給料が変わるには<em class="kw">国会で給与法を改正する必要がある</em>の📋 月例給の改定は令和8年（2026年）4月にさかのぼって適用する内容で勧告されてるけど、法改正が通るまでは確定じゃないのよ⚖️
