## なんで「著作権侵害だ」と<span class="mk">言うこと</span>が問題なの？⚖️

ここが一番おもしろいとこ。だって「うちのキャラを無断で使われてると思う」って言うの、普通の抗議っぽく聞こえるじゃん？　でも裁判所の判断は違ったの。かすみちゃんに整理してもらうね📋

{{< hukidashi who="aashi" >}}「著作権を侵害されてると思う」って言っただけで賠償になるの？意見を言うのもダメなん？？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}本件において裁判所は、須崎市が表明した見解を<strong>虚偽の事実の拡散による営業妨害</strong>に当たると判断いたしました。あわせて、それによって管理会社の<strong>営業上の信用が低下した</strong>と認定しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え〜つまりどゆこと？？「感想」じゃなくて「事実の主張」として見られたってこと？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}<strong>著作権を侵害している</strong>という表明は、単なる評価ではなく<strong>事実の主張</strong>として受け取られるものであります。これが公に示されますと、取引の相手方はその事業者と関わることを控える方向に働きます。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}あ〜！！つまり取引先からしたら「権利を侵害してるキャラを使ったら、うちまで巻き込まれるかも」ってなるじゃん😨{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}イベントの主催者や商品の企画者は、法的な紛争を抱えているとされるキャラクターの起用を避ける判断をいたします。その結果、出演や商品化の機会が減少し、<strong>営業上の信用の低下</strong>という損害が生じ得るという構造でございます。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}なるほど完全に理解した💡　キャラビジネスって<strong>呼ばれること</strong>で成り立ってるから、「あのキャラ権利ヤバいらしいよ」が広まった時点でもう売り上げに穴が開くのね🦦{{< /hukidashi >}}

## 賠償金って<span class="mk">誰のお金</span>から出るの？💰

そしてここ、ちゃんと言っておきたいとこ。

<strong>須崎市が払う賠償金は、市民の税金から出るお金なの。</strong>

1審で786万円、2審で1,887万円。これ全部、市民が納めたお金の中から出ていく話じゃん💸　もちろん市としては「苦情が市に来て困ってたから対応した」という事情があったし、誰かが悪意でやったわけじゃないと思う。でも<strong>結果として市民の負担になる</strong>のは変わらないのよ🥹

{{< hukidashi who="aashi" >}}自治体の裁判って、負けたら市民のお金が減るってことだもんね…🥹{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}地方公共団体の支出は、一般に当該団体の予算から行われるものと認識しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}だから「最初から契約と権利をちゃんとしとこうね」が、けっこう重い教訓になるのよ⚖️{{< /hukidashi >}}

## まとめ📝

- <strong>2026年10月7日、知的財産高等裁判所が控訴審の判決</strong>を出した⚖️
