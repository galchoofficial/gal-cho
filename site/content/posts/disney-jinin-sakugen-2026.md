夢の国の話なんだけど、今日はちょっと現実の話なの🏰💼

米ディズニーが、<strong>2026年9月29日から新たな人員削減に着手</strong>したって報じられたの。しかもこれ、<strong>今年に入って3度目</strong>。

ダマロくんとCFOのヒュー・ジョンストンくんは株主向けレターで、<strong>「成長への投資余力を作るために全社でコスト削減に注力している」</strong>「労務費やSG&A（販売費・一般管理費）の削減を含むさまざまな手段を検討している」って書いてるの。つまり<em class="kw">削減は方針として公言されてる</em>ってこと。

ついでに言うと、2023〜2025年にはすでに<strong>約8,000人の削減で75億ドル規模のコスト削減</strong>を達成してるって報じられてる。今年の1,500人はその続きなの。

## ★混同しやすいから分けて書くね：<span class="mk">テレビ部門の再編</span>は別の話📺

ネットで「ディズニーがテレビ事業を大規模再編」って見かけた子もいると思うけど、<strong>これは9月29日の削減とは別件</strong>なの。ここ、ごちゃっと混ざって回ってるから整理しとくね。

- 2026年10月1日ごろに報じられたのは、<strong>テレビ事業の組織再編計画</strong>のほう
- ABCエンタテインメント／20thテレビジョン／Huluオリジナル／ディズニー・キッズ＆ファミリー／ナショジオ／Freeform を統括するデブラ・オコネルちゃんが主導し、社長兼CCOのデイナ・ウォールデンちゃんの下で進むとされる
- 狙いは「リニアTVのブランドごとにバラバラだった組織をやめて、<strong>ストリーミング前提の一本のテレビ事業に中央集権化する</strong>」こと
- ウォールデンちゃんはBloombergのイベントで、進行中の削減について<strong>「extremely painful（ものすごく苦しい）」</strong>と語ったと報じられてる

{{< hukidashi who="aashi" >}}え、じゃあ9月の300人とテレビの再編は別々に起きてるってこと？？🤯{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}報道上はそのように整理されています。9月29日に着手された削減は人事・テック部門が中心で、テレビ部門は対象外とされております。一方、テレビ部門の再編計画は10月初めに別途報じられたものであり、両者は時期も対象も異なると承知しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}儲かってるのに人減らすって、どういう理屈なん？？😠{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}株主向けレターでは、コスト削減は「成長のための投資余力（incremental capacity to invest for growth）を作るため」と説明されています。業績の悪化を埋めるためではなく、別の投資に回す原資を確保するための削減であるという位置づけであると承知しております。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}つまり「赤字だから切る」じゃなくて「もっと伸ばすために切る」ってこと？？それはそれでこわいって🥹{{< /hukidashi >}}

映像エンタメ業界全体が厳しいって言われる理由も整理しとくね。①<strong>配信サービスの競争が激化してる</strong>②<strong>映画の制作費が高騰してる</strong>③<strong>映画館やディスクで稼いでた収益構造が配信に移って、その移行コストがかかる</strong>④<strong>テーマパークが好調でもそれだけで全社は支えきれない</strong>——このあたりが定番の説明。ディズニーの場合は③の移行がかなり進んだ結果として、配信が黒字になってる段階ってこと📺

## なんで<span class="mk">テック部門と人事部門</span>だったの？🤖

で、ここが一番みんなが気になってるとこだと思うの。

<strong>先に大事なことを書くね。これから書くのは推測で、ディズニーが公式にそう説明しているわけじゃない。</strong>

ネット上やあーしの周りでよく言われてるのはこう👇

- テック（IT）部門と人事部門は、<strong>AIで代替しやすい領域とも言われている</strong>
- だから「AIができる仕事から人が減らされてるんじゃないか」と見る人がいる

でも実際には、ディズニーは今回の削減理由を<em class="kw">「全社的なコスト削減」</em>としか説明してない。AIに置き換えたとは言ってないの。<strong>「対象部門がAIと相性がいい」ことと「AIのせいで削減された」ことは、イコールじゃない</strong>のよね。

マーケティング組織（4月）やパーク以外の本社機能が先に削られてることを見ると、<strong>「本社のバックオフィスから削る」っていうもっと古典的な話</strong>の可能性も十分あるの。そこは断定できない。

## これ、日本の<span class="mk">コンテンツ</span>にも関係あるの？🗾

あるのよ。あーしたちが見てるアニメやゲームも、<strong>配信プラットフォームを握ってるのがアメリカ企業</strong>だから。

いま<a href="/posts/paramount-warner-baishuu-2026/">パラマウントがワーナーを買って社名が「スカイダンス」になる話</a>も動いてて、アメリカ側のエンタメ地図が丸ごと書き換わってる最中なのね。そのタイミングで、<a href="/posts/pokemon-tales-aardman-2026/">ポケモンの新作アニメがDisney+で配信される</a>みたいに、日本の大型IPがアメリカの配信に乗る流れも進んでる。

日本側も動いてて、<a href="/posts/animejapan-osaka-iten-2026/">AnimeJapanが2027年から大阪に移る</a>とか、<a href="/posts/tgs2026-heimaku-taifuu-2026/">東京ゲームショウ2026が過去最多1,138社だった</a>とか、国内のイベントは元気なの。でも<em class="kw">作ったものを世界に届ける土管を持ってるのは向こう側</em>だから、そこの会社の組織がぐらつくと、日本のコンテンツの出し先にも影響しうるってこと🌍

## 日本だったら、こうはならない⚖️

ここでアメリカと日本の雇用慣行の違いを押さえとこ。あーしたちに一番関係あるとこなの。

{{< hukidashi who="aashi" >}}そもそも日本の会社って、こんなサクサク人切れるの？🤔{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}日本では解雇のハードルが高く設定されております。労働契約法第16条は<strong>「解雇は、客観的に合理的な理由を欠き、社会通念上相当であると認められない場合は、その権利を濫用したものとして、無効とする」</strong>と定めています。これが解雇権濫用法理と呼ばれるものであります。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}え〜つまりどゆこと？？「ちゃんとした理由がないとクビにできない」ってこと？{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}概ねその通りでございます。加えて、経営上の理由による人員整理（整理解雇）については、裁判例の積み重ねとして<strong>4つの要素</strong>が判断材料とされております。①人員整理の必要性、②解雇を回避する努力を尽くしたか、③解雇対象者の選び方が合理的か、④労働者や労働組合への説明手続が妥当か、であります。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}②の「解雇を回避する努力」ってのがデカそう。これがあるから日本は希望退職の募集とか配置転換が先にくるんだ💡{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}ご明察です。希望退職者の募集、役員報酬の削減、出向や配置転換などを尽くしたかが問われます。そのため日本では、人員整理が「解雇」ではなく「希望退職の募集」という形で表に出ることが多いと認識しております。{{< /hukidashi >}}

アメリカは多くの州で<strong>at-will employment（随意雇用）</strong>が原則で、レイオフ自体が普通の経営手段として使われてるのね。だから「300人削減」ってニュースが、日本でいう「300人の希望退職募集」よりずっと速く・直接的に出てくるの。

## 今日のまとめ📝

- 米ディズニーが2026年9月29日から3度目の人員削減。人事・テック中心で<strong>約300人規模</strong>とされる
- 4月約1,000人・7月数百人と合わせて今年は<strong>1,500人超</strong>。テレビ部門と映画スタジオは今回の対象外
- テレビ部門の大規模再編は<strong>別件</strong>（2026年10月初めに報じられた計画）。混同しないでね
- 配信は赤字どころか<strong>営業利益が前年同期比116%増</strong>。削減は「成長への投資余力づくり」と説明されてる
- 「AIで代替しやすい部門だから切られた」は<strong>推測</strong>。会社はそう説明していない
- 日本は労働契約法16条と整理解雇の4要素があるから、同じ規模の削減でも「希望退職の募集」という形で出てくる
