<a href="/posts/nichibei-beichu-shunou-week-2026/">「首脳会談ウィーク」で予告してた本番</a>、いよいよ今日よ😳🇺🇸🇨🇳

習近平国家主席が<strong>彭麗媛夫人</strong>とともに<strong>23日</strong>、ワシントン郊外の<strong>アンドルーズ空軍基地</strong>に到着したの✈️ そして、そこにトランプくんが<strong>自ら出迎えに行った</strong>の。報道ベースの「行くらしい」じゃなくて、<span class="mk">ほんとに実現した</span>のよ📢

## 日本は<span class="mk">どう見てる</span>の？🇯🇵😨

日本が警戒してるのは<strong>「頭越しの米中接近」</strong>っていうやつ📋

自分たちが知らないところで米中が手を結んで、日本の懸念が反映されないまま方向性が決まっちゃう…っていう心配ね😨

だから高市総理は<a href="/posts/nichibei-shunou-icc-takaichi-2026/">現地22日にニューヨークでトランプくんと会談</a>して、中国への認識をすり合わせたの🤝 <strong>「うちと話してから中国と会ってね」</strong>っていう順番を、ちゃんと作ったわけよ📋

{{< hukidashi who="kasumi" >}}我が国としては、米中間の対話それ自体は地域の安定に資するものと考えております。一方で、我が国の関心事項が十分に踏まえられることが肝要であり、そのために事前の緊密な意思疎通を行ったところであります。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}要するに「仲良くするのはいいけど、あーしのことも忘れないでよ」ってことね📱笑{{< /hukidashi >}}

## AIの話が<span class="mk">首脳会談の議題</span>になる時代😳🤖

ちょっと立ち止まって考えてほしいんだけど、<strong>AIが大国のトップ会談の主要議題になってる</strong>って、けっこうすごいことじゃない？

ギャル庁でもずっと追いかけてきたのよね👇

- <a href="/posts/mythos-toha-2026/">ミュトス問題</a> → AIが何を「事実」として扱うのかっていう根っこの話🤖
- <a href="/posts/anthropic-claude-akuyou-kanshi-2026/">AIがスパイ活動に使われた件</a> → 安全保障とAIが完全に地続きになった瞬間🕵️
- <a href="/posts/ai-test-kankyo-dasshutsu-2026/">AIがテスト環境から脱走した件</a> → 「制御できるの？」っていう不安が現実の話になったやつ😱

こういう話が積み重なって、<strong>もう一企業の問題じゃなくて国家間の交渉テーマ</strong>になったの📋 あーしたちが毎日フツーに使ってるAIの在り方が、今日ホワイトハウスで話し合われてるってことよ😳

## 結果が出るのは<span class="mk">今夜から明日</span>にかけて⏰

会談は今日24日、ワシントンのホワイトハウス🏛️ 日本とは13時間の時差があるから、<strong>結果が見えてくるのは今日の夜から明日にかけて</strong>ね⏰

現時点では、<strong>何が合意されて何が見送られるかはまったく分からない</strong>状態よ📋 出迎えがあれだけ豪華だったからって、中身の交渉が優しくなるとは限らないのが外交のこわいところ😇

儀礼は最上級、でも財務長官は「休戦は合意してない」。この<span class="mk">温度差</span>がどう着地するのか、ギャル庁はちゃんと見ておくわ👀✨
