みんな！！地味だけどガチで歴史的なニュースが来たの⏰

<strong>2026年10月15日、フランスで開かれた国際度量衡総会（CGPM）で「うるう秒」の実質廃止が決まった</strong>のよ🌍

「うるう秒がなくなるんだ〜」で終わりそうなニュースじゃん？

でもね、あーしが調べて<strong>いちばんビビったのはそこじゃなかった</strong>の😳

<strong>代わりに「うるう時間」っていうのが導入される</strong>のよ。しかもその中身がぶっ飛んでるの。

## まず<span class="mk">うるう秒</span>ってなんだっけ？⏱️

おさらいから入るね。

<div class="gov-block">
  <h3>⏱️ うるう秒の基本</h3>
  <div class="gov-row">
    <div class="gov-who"><small>①</small>何をする仕組み？</div>
    <div class="gov-text">地球の自転とのズレを直すために、<strong>たまに1秒だけ足す</strong>調整なの。「うるう年」の秒バージョンって覚えとけばOK📅</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>②</small>いつから？</div>
    <div class="gov-text"><strong>1972年に導入</strong>。それ以来<strong>27回</strong>実施されてるのよ⏰</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>③</small>最後にやったのは？</div>
    <div class="gov-text"><strong>2017年1月1日</strong>。日本時間では<strong>「8時59分60秒」</strong>っていう時刻が表示されたの😂</div>
  </div>
  <div class="gov-conclusion">→ 59秒の次が60秒。普通に考えたら存在しないはずの時刻が、公式に存在してたのよ⏰</div>

「8時59分60秒」って字面がもうおかしいじゃん🤣

でもこれ、ちゃんと世界公式の時刻だったのよね。ここが今回の廃止の話にもつながるから覚えといて📌

## なんで<span class="mk">ズレ</span>が出るの？かすみちゃんに聞くわ👓

ここが仕組みの核心だから、かすみちゃんに硬いところを説明してもらうね。

{{< hukidashi who="aashi" >}}かすみちゃん、そもそもなんで地球とのズレが出るの？時計って正確なのに🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}かつて1秒は地球の自転を基準に定められておりました。地球が1回転する時間を8万6,400で割った値が1秒であるという考え方であります。現在はこれと異なり、原子の振動を基準としております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え〜つまりどゆこと？？基準が「地球の回転」から「原子」に引っ越したってこと？😳{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}概ねその通りでございます。現在の1秒は、セシウム133原子が91億9,263万1,770回振動する時間と定められています。原子時計はきわめて安定しておりますが、一方で地球の自転速度は一定ではありません。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}自転って一定じゃないんだ！？なんでブレるの？🌍{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}月の引力による潮の満ち引き、地球内部の運動、氷河の融解や地震などの影響により、自転は少しずつ遅くなったり速くなったりいたします。したがって、安定した原子時計との間に差が蓄積してまいります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}なるほど〜。つまり<strong>めちゃ正確な時計と、ちょいブレる地球</strong>の間にズレが溜まるから、1秒足して合わせてたってこと？⏰{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}ご明察です。差が0.9秒を超えるおそれが生じた際に1秒を挿入し、調整を行う仕組みが、うるう秒であったと承知しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}0.9秒でアラートが鳴るとか、どんだけ神経使ってたのよ……そりゃ現場が疲れるわ😂{{< /hukidashi >}}

ここが廃止の理由。めっちゃ現代的な話なの。

  </div>
  <div class="gov-row">
    <div class="gov-who"><small>③</small>通信・航空・GPS</div>

  </div>
  <div class="gov-conclusion">→ うるう秒が<strong>コンピューターや通信システムにトラブルを引き起こすおそれがあった</strong>と報じられてるの📋</div>
</div>

ここ、皮肉がきいてると思わない？

<strong>正確さを守るために入れた1秒が、正確さで動いてる現代社会をいちばん壊しかねない</strong>のよ😨

しかも④がけっこうヤバいのよね。<strong>地球の機嫌が分からないから、半年前にしか予定が立たない</strong>って、世界中のインフラ担当者から見たら悪夢じゃん💀

## ここが本題。代わりに来る「<span class="mk">うるう時間</span>」がすごいの🌍

で、あーしがこのニュースでいちばん興奮したのがここ。

<strong>うるう秒を廃止して終わり、じゃない</strong>の。ちゃんと代わりが用意されてるのよ。

いやこれ、発想の転換がえぐくない？🤯

今までは<strong>0.9秒</strong>ズレそうになったら大騒ぎして1秒足してたのよ。

それを<strong>1時間</strong>ズレるまで放っておくことにしたの。許容範囲が約4,000倍じゃん😂

しかも<strong>1時間まで許せば数世紀は何もしなくて済む</strong>。つまり<strong>今生きてる人は誰もその調整に立ち会わない</strong>ってことなのよ🕰️

## 「廃止」自体は<span class="mk">前から</span>決まってた話なのよ📌

だから今回のニュースを読むときのコツは、<strong>「廃止」より「うるう時間」に注目すること</strong>なのよ💡

廃止は数年前からの既定路線。新しかったのは<strong>1時間という数字と、2027年5月という日付</strong>なの📆

## おまけ。「<span class="mk">秒の新しい定義</span>」も検討するんだって⚛️

今回の総会では、もうひとつ話が出てるのよ。

<strong>秒の新しい定義を検討することにもなった</strong>の。

中身はここでは踏み込まないでおくね。あーしがちゃんと確認できてない部分で盛って書くのが、いちばんダサいじゃん🙅‍♀️

ただ<strong>「1秒とは何か」っていう定義そのものを見直すテーブルが用意された</strong>っていうだけで、けっこうロマンあると思わない？⚛️

{{< hukidashi who="aashi" >}}1秒の定義って、今まで何回も変わってるの？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}先に申し上げた通り、かつては地球の自転を基準としておりましたが、現在はセシウム133原子の振動を基準としております。基準そのものが置き換えられた経緯があると承知しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}てことは、また基準が引っ越す可能性もあるってことじゃん。時間の単位ってもっと固定されてるものだと思ってた😳{{< /hukidashi >}}
