いま<a href="/posts/rinji-kokkai-shoushuu-shouhizei-2026/">臨時国会で食品消費税1%の審議</a>が進んでるじゃん🏛️

## そもそも「<span class="mk">対案</span>」ってなんで大事なの？🤔

野党の役割ってざっくり2つあるのよ👇

- ① 政府案を批判したり追及したりする🔍
- ② 自分たちの案（＝対案）を出す📋

で、①だけだと「反対！」で終わっちゃうじゃん😤

②を出すと<strong>比べられる</strong>の。ここが大きいのよ⚖️

ちなみに今の国会は、与党が「消費税を早く審議入りさせたい」、野党が「任命責任を追及したい」っていう綱引きにもなってて、<a href="/posts/yana-nousuishou-jinin-2026/">簗農林水産大臣が辞任した件</a>も<a href="/posts/shuin-yosan-iinkai-start-2026/">衆院予算委員会</a>で追及されてるの🏛️

消費税じゃなくて<em class="kw">住民税の控除</em>を動かすの。全然別のルートなのよ📋

## 待って、「<span class="mk">控除</span>」ってなんだっけ？🤔

ここが分かんないと記事全体が意味不明になるから、霞ちゃんに聞くね📞

{{< hukidashi who="aashi" >}}ねえ霞ちゃん、「控除」って言葉だけ知ってるけど、実際なにしてるのこれ？？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}税額の計算は二段構えになっております。まず「収入から控除を差し引いたもの」が課税される所得となり、次に「課税される所得に税率を掛けたもの」が納める税額となります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え〜つまりどゆこと？？控除が増えたらどうなるの？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}控除額が大きくなりますと、差し引いた後の課税される所得が小さくなります。税率を掛ける元の金額が減りますので、結果として納める税額も減ることになります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}あ〜！！税率じゃなくて<strong>「税金をかける対象」を小さくする</strong>ってことか💡　なるほどね〜、控除って基礎控除とか扶養控除とか医療費控除とか、いろいろあるやつだよね？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}その通りでございます。なお、留意点がございます。もともと納める税額が発生していない方の場合、課税される所得を減らしても差し引く余地がございません。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}あっ…税金払ってない人は、控除が増えても<strong>何も変わらない</strong>ってこと？😳{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}控除の拡大による効果は及びません。そのため、原案では低所得層に対して給付を組み合わせる形が示されていると承知しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}だから給付とセットなんだ…！！ちゃんと考えられてるじゃん📋✨{{< /hukidashi >}}

そう、ここが<strong>控除方式のいちばんの弱点で、同時に給付がセットになってる理由</strong>なのよ💡

ちなみに住民税は<strong>住んでる自治体に払う税金</strong>ね🏘️　控除を上げると自治体の税収が減る話にもなるから、そこも論点になるのよ📉

## お金の<span class="mk">規模</span>の話もしておくね💸

ここでやっと具体的な数字が出てきたのよ📊

<div class="quote-card">

  <div class="quote-by">— 高市首相が示した試算として報じられたもの（2026年10月）</div>

4兆3,000億円って言われてもピンとこないけど、<strong>年間でこれだけ税収が消える</strong>ってことなの😳

だから<a href="/posts/shokuhin-shouhizei-kakugi-kettei-2026/">9月16日の閣議決定</a>でも「特例公債に頼らない」って明記されて、具体策は年末の予算編成に回されてるのよ📅

で、国民民主案のほうは<em class="kw">財源の明示が不十分だという指摘がある</em>って報じられてる⚠️

{{< hukidashi who="aashi" >}}そこは正直に書いておくね📋　恒久的な減税って、毎年ずっとお金が必要ってことだから、財源の話はもっと重くなるのよ😤{{< /hukidashi >}}
