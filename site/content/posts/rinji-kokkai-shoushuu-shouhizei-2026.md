## まず減税の中身を<span class="mk">正確に</span>おさらい🍙

ニュースだと「食料品の消費税が1%」ってざっくり言われがちだけど、法律の世界ではもうちょい厳密なの。

{{< hukidashi who="aashi" >}}え、食料品と飲食料品って違うの？？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}異なります。今回対象となるのは、消費税の軽減税率が適用される<strong>「飲食料品」</strong>であります。酒類や外食などは軽減税率の対象外とされており、今回の引下げの対象にも含まれません。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}つまり今まで8%だったスーパーのやつが対象で、お酒と外食は10%のまま据え置きってこと？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}ご明察です。軽減税率の対象範囲をそのまま用いる整理と承知しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}1%なのに0.78%と0.22%って分けるの、なんで？？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}消費税は国税部分と地方消費税部分から構成されております。引下げ後も同様の構成を維持する必要があるため、1%のうち国税を0.78%、地方消費税相当分を0.22%とする整理が示されています。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}なるほど、国と自治体で分けっこするお金だから1%でも分け方を決めとかなきゃダメなのね💰{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}てことは「支援金は2029年度から」じゃなくて「支援金は2027年4月から、2029年度からは給付付き税額控除にバトンタッチ」ってこと？？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}その通りでございます。就業者負担軽減支援金は飲食料品の消費税率の引下げと<strong>同時期に開始する</strong>ものとされています。一方、給付付き税額控除は中・低所得者に重点を置いた恒常的な制度として、2029年度からの本格的な導入が想定されております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え、じゃあなんで1%にするだけじゃなくて支援金もいるの？1%ならもう十分安くない？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}大綱では、引下げ後に残る<strong>1%相当分</strong>に当たる規模（年約6,000億円程度）の範囲内で、中低所得の就業者に対して支援金を支給することにより、飲食料品に係る消費税の負担を実質的にゼロとする趣旨が示されています。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}あ〜！！税率はゼロにしないけど、残った1%分を支援金で返すから結果ゼロみたいになるってことね💡　6月に決着した「1%＋給付で実質ゼロ」の折衷案のやつじゃん！{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}概ねその通りであります。税率を完全にゼロとしない設計は、事業者の仕入税額控除の取扱いに関する課題を回避する意味も持つと整理されています。{{< /hukidashi >}}

ここを押さえると、ニュースで「支援金」って出てきたときに<strong>2027年の話なのか2029年度の話なのか</strong>がちゃんと聞き分けられるようになるの👀✨

そしてもうひとつ。日本経済新聞は<strong>参議院での審議が難所になる</strong>という見方を伝えてるの。与党は成立を目指してるけど、野党側は充実した審議を求めてるから、ここが山場になりそう🏛️

{{< hukidashi who="aashi" >}}衆議院で通っても参議院でまた揉めるってこと？？🥹{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}法律案は両議院で可決されて初めて法律となります。したがって、一方の議院の議決のみでは成立いたしません。{{< /hukidashi >}}

## まとめ📝

- 臨時国会は<strong>10月5日召集、12月12日までの69日間</strong>。政府提出法案は<strong>21法案</strong>🏛️
- 対象は<strong>飲食料品</strong>（お酒と外食は入らない）。税率は<strong>8%→1%</strong>で、内訳は国税0.78%＋地方消費税相当分0.22%💸
- 期間は<strong>2027年4月1日から2029年3月31日までの2年間</strong>⏰
- <strong>就業者負担軽減支援金は2027年4月から減税と同時スタート</strong>。年約6,000億円の範囲で中低所得の就業者に支給して実質ゼロ化💰
- <strong>2029年度から本格導入されるのは給付付き税額控除</strong>（恒常的な制度）。今回の減税＋支援金はそこまでの「つなぎ」🔁
- 財源は「特例公債に頼らない」と明記、具体策は<strong>年末の予算編成</strong>📅
- 争点は<strong>財源・2年限定の是非・外食との格差・支援金の中身</strong>、そして<strong>参議院が難所</strong>になるとの見方⚔️
