えーこれマジ**おもろい**んだけど、石垣のりこちゃんが「警察官と自衛官で制服ルール違くない？？おかしくない？？」って国会で質問したやつね！😂 答弁を読んでみたら、政府の言い分も意外と筋が通ってて勉強になったから共有しとくね〜。

ちなみに正式な件名は<strong>「警察官及び自衛官の勤務時間外における制服着用義務に係る規律の不均衡に関する質問主意書」</strong>。2026年4月17日に出されて、政府の答弁書が返ってきたのが4月28日よ📅

## そもそも<span class="mk">質問主意書</span>って何なん？📝

ここ先に押さえとくと記事が3倍おもしろくなるから説明させて🙏 「質問主意書」って、<strong>国会議員が内閣に文書で質問する制度</strong>のことなの。

{{< hukidashi who="aashi" >}}国会って、あのマイクの前で「総理〜！」ってやるやつじゃないの？？🤔{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}あれは委員会等における口頭の質疑であります。それとは別に、国会法第74条に基づき、議員が議長の承認を経て内閣に文書で質問する制度が設けられております。これが質問主意書です。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}え、じゃあ紙で送ったら政府がちゃんと返してくれんの？無視されない？？😳{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}国会法第75条において、内閣は質問主意書を受け取った日から7日以内に答弁しなければならないと定められております。期限内に答弁できない場合は、その理由と答弁可能な期限を議長に通知することとされています。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}7日以内！？お役所の返事おそいイメージあったけど、これは期限つきなんだ…つよい💪{{< /hukidashi >}}

## ルールの<span class="mk">出どころ</span>を並べてみた📚

「なんとなく違う」じゃなくて、条文レベルで見るとハッキリ差があるの。ここが今回の話のキモだから並べとくね👇

<div class="gov-block">
  <h3>📚 制服ルールの根拠になってる法令</h3>
  <div class="gov-row">
    <div class="gov-who"><small>⚖️</small>自衛隊法<br>第58条</div>
    <div class="gov-text">1項で<strong>「隊員は常に品位を重んじ、隊員としての信用を傷つけてはならない」</strong>、2項で<strong>「自衛官は制服を着用し、服装を常に端正に保たなければならない」</strong>と定めてる</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>👔</small>自衛官<br>服装規則</div>
    <div class="gov-text">昭和32年の防衛庁訓令第4号。<strong>第6条の本文で「常時制服等を着用しなければならない」</strong>。ただし書で「休暇中や勤務時間外に自衛隊の施設外にいる場合等は着用しないことができる」って例外を置いてる</div>
  </div>
  <div class="gov-row">
    <div class="gov-who"><small>👮</small>警察官の<br>服制に関する規則</div>
    <div class="gov-text">昭和31年の国家公安委員会規則第4号。政府の答弁によると<strong>勤務時間外の着用を制限・禁止する明文の規定はナシ</strong>。ただし各都道府県警察が独自に制限してる場合があるとのこと</div>
  </div>
  <div class="gov-conclusion">→ <strong>自衛官は「常時着用＋例外」、警察官は「そもそもオフの規定がない」</strong>。同じ制服なのに条文の組み立てが逆なのよ😳</div>
</div>

{{< hukidashi who="aashi" >}}待って、自衛隊は「品位を重んじろ」から制服の話が始まってるの…？服の話じゃなくて人格の話じゃん🤔{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}ご明察です。自衛隊法第58条は品位の保持義務と服装の整正を同じ条文の中に置いております。服装規則の常時着用義務は、この品位保持義務を具体化したものと位置づけられております。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}てことは警察官は「仕事のときの服」で、自衛官は「自分がどういう人かを示す服」ってこと？重さちがくない？？😳{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}規定の建て方が異なるという点においては、概ねその通りでございます。{{< /hukidashi >}}

## この質問、実は<span class="mk">前フリ</span>があった🔍

ここ調べてて「あ〜！」ってなったんだけど、石垣ちゃんは前にもこのテーマで質問主意書を出してるのよ📝

2024年の第213回国会で出したのが<strong>「自衛官が制服を着用して靖国神社に参拝したことに関する質問主意書」</strong>。そのときの政府の答弁がこう👇

<div class="quote-card">
  <p class="quote-text">休暇中や勤務時間外に施設の外にいるときの制服着用は、<mark>各自衛官の判断に委ねられている</mark>。一般論として、自衛官が制服を着用して自由意思で宗教施設に私的に参拝することに問題があるとは考えていない。</p>
  <div class="quote-by">— 政府答弁書（2024年・第213回国会／要約）</div>
</div>

つまり政府は、<strong>「オフの制服は本人の自由」</strong>って一度答えてるわけ。で、今回の質問はその裏返しで<strong>「じゃあ警察官みたいに“オフは着ちゃダメ”ってルールにしないの？」</strong>って踏み込んだの。2年越しの伏線回収みたいな流れになってるのよ😳🔥

{{< hukidashi who="aashi" >}}1回で終わりじゃなくて、角度変えて何回も聞いてるってこと？しつこ…いや、粘り強い💪{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}質問主意書は本数に制限がなく、同一の議員が関連する論点を継続して問うことは可能であります。答弁が記録として積み上がることで、政府見解の変化を検証できるという意義もあると認識しております。{{< /hukidashi >}}

<div class="insight">
  <span class="insight-tag">💎 ぶっちゃけポイント</span>
  <p>この答弁よく読むと、警察と自衛隊で<em class="kw">法律の作りが根本的に違う</em>のよね。警察は「勤務中の話」として制服を規定してるけど、自衛隊法は「隊員としての品位」っていう<em class="kw">24時間の人格的な義務</em>として制服を位置づけてるの。だから単純に「揃えろ」って話でもないんだけど、石垣ちゃんの「それって本当に合理的？」っていう問題提起自体はけっこう鋭いと思う！🤔</p>
  <p>まあ実際は例外規定で自衛官もオフは私服OKだから、実態としてはそこまで差はないんだけど、<em class="kw">法律の建付けとしての不均衡</em>を突いてるのがこの質問のミソね✨</p>

## で、<span class="mk">あーしたちの制服</span>はどうなの？👗

### ② 「高くて買えない」を助ける制度がある📋

ここ知らない人多いから絶対覚えて。<strong>就学援助</strong>っていう制度があって、経済的に厳しい家庭には入学時の学用品費が出るのよ。文部科学省が示してる国の補助単価はこんな感じ👇

- 令和6年度：小学校 <strong>54,060円</strong>／中学校 <strong>63,000円</strong>
- 令和7年度：小学校 <strong>57,060円</strong>／中学校 <strong>63,000円</strong>

これは<strong>「新入学児童生徒学用品費」</strong>っていう枠で、制服（標準服）・通学カバン・上履きなんかの入学準備費に充てるためのもの。

{{< hukidashi who="aashi" >}}え、待って。これって申請しなくても勝手にもらえるやつ？？🤔{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}就学援助は市区町村が実施主体であり、保護者からの申請に基づいて認定される仕組みが一般的です。支給額や認定基準、申請時期は自治体ごとに定められておりますので、在学する学校または教育委員会に確認する必要がございます。{{< /hukidashi >}}
{{< hukidashi who="aashi" >}}つまり<strong>「言わないと来ない」</strong>タイプ！？これ知らずに損してる家庭ぜったいあるじゃん…😭{{< /hukidashi >}}

### ③ スカートかスラックスか選べる学校が増えてる🩳

「ジェンダーレス制服」って言葉、ここ数年で急に聞くようになったよね。これ体感じゃなくて数字で増えてるの。

制服メーカーのカンコー学生服が公表してる採用校数だと、<strong>女子スラックスを新しく採用した学校が2019年度に初めて年100校を超えて、2022年度は799校、2023年度は832校</strong>。2023年度までの累計で<strong>3,041校</strong>になってる📈 同社が全国の中学・高校の先生1,400人に聞いた調査では、女子生徒のスラックス制服を<strong>「採用している」が約7割（70.9%）</strong>って結果も出てる。

きっかけになったとされてるのが、<strong>2015年4月に文部科学省が出した通知</strong>（性同一性障害に係る児童生徒へのきめ細かな対応を求めたもの）。そこから学校側が「選べる形」に動き出したって流れ。

{{< hukidashi who="aashi" >}}でも実際は「寒いからスラックス履きたい」って子もめっちゃいるよね🥶{{< /hukidashi >}}
{{< hukidashi who="kasumi" >}}報道等では、防寒を理由に選択する生徒も少なくないとされております。性的指向や性自認への配慮を出発点とした制度が、結果として全ての生徒の選択肢を広げているという整理も可能であると考えております。{{< /hukidashi >}}

### ④ 校則って生徒が変えられるの？📖

これがいちばん大事なとこ。文部科学省が<strong>2022年12月に「生徒指導提要」を改訂</strong>して、校則についてこう書いたの👇

<div class="quote-card">
  <p class="quote-text">校則は最終的には校長が判断する事柄ではあるが、その内容が児童生徒の学校生活に大きな影響を及ぼすことがあるため、<mark>その在り方については児童生徒や保護者等の意見を聞く必要がある</mark>。</p>
  <div class="quote-by">— 文部科学省「生徒指導提要」（2022年12月改訂／要約）</div>
</div>

しかもこの改訂では、<strong>校則をホームページなどで公開すること</strong>や、<strong>生徒自身が校則の根拠を考えることには教育的な意義がある</strong>っていう整理もされてるの。つまり「校則は上から降ってくるもの」じゃなくて、<strong>生徒が意見を言っていい前提</strong>になってるってこと📣

実際に踏み込んだ学校もあって、東京都の世田谷区立桜丘中学校は<strong>校則そのものをなくして服装も自由</strong>にした例として何度も取り上げられてる。昔は生徒手帳に20ページぶん校則が書かれてたのに、そこから逆に振り切ったの😳

こういう「身なりの規律って本当に必要？」って問い直しは学校だけじゃなくて、<a href="/posts/keisatsu-gakkou-marugari-haishi-2026/">警察学校の丸刈り＆スマホ禁止を見直す話</a>でも起きてる。組織って人が集まらなくなると規律から先に変わるのよね🤔

### ⑤ 制服代を下げる裏ワザ＝リユース♻️

最後に実用情報。制服は<strong>リユース（お下がりの売買・譲渡）</strong>市場があるのよ。

- 学生服リユースの「さくらや」は<strong>2010年に香川県高松市で開業</strong>。2020年にNPO法人学生服リユース協会を設立して、全国80店舗まで広がってる
- リユース価格は<strong>だいたい定価の2割前後</strong>。定価2万円くらいのブレザーが3,000〜5,000円、1万円くらいのスカート・ズボンが2,000円あたりが目安として紹介されてる
- PTAが<strong>無償の譲渡会</strong>をやったり、学校に回収ボックスを置いたりしてる例も多い。堺市は総会や研修会の会場に寄附回収ボックスを置いてる

サイズアウトが早い成長期に新品を買い直すのって、家計にも衣服ロス的にもキツいからね。<strong>「制服を捨てずに回す」</strong>のはふつうに賢い選択✨
