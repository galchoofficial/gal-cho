## 会期延長の<span class="mk">可能性</span>は？🤔

{{< hukidashi who="aashi" >}}
そういえば国会って延長できるんだっけ？？
{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}
通常国会は1回に限り会期延長が認められております。重要法案の残務がある場合、会期を数日〜数週間延長することは過去にも事例がございます。
{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}
じゃあ6/21で終わらない可能性もあるってこと？？
{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}
その通りでございます。防災庁設置法案など重要法案が未決着の場合、延長判断が下される可能性は十分にあります。
{{< /hukidashi >}}
