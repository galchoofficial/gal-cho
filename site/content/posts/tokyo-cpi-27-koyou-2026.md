東京23区の物価の数字が出たよ📊 <strong>コアCPIが前年同月比2.7%上昇</strong>💸

前の月が1.8%だったから、見出しだけ見ると<strong>「え、1ヶ月で急にヤバくなった？」</strong>って思うじゃん。あーしも最初そう思った。

でもね、調べたら<strong>そういう話じゃなかった</strong>のよ😳 ここが今日いちばん書きたいところ。

消費者物価指数（CPI）っていうのは、<strong>物の値段がどのくらい上がったかを測る数字</strong>。総務省が毎月発表してて、食品・電気代・家賃・サービスとか、いろんな品目を調べて平均を出すのよ🧾

で、<strong>東京23区の数字は全国の数字より先に公表される</strong>から、「全国もこうなりそう」っていう先読みに使われるの。だからニュースになりやすい📺

## ★ここが本題。「いきなり跳ねた」わけ<span class="mk">じゃない</span>の💡

今回のニュース、報じ方のキーワードが<strong>「政策要因の影響剥落（はくらく）」</strong>なのよ。

剥落って、要するに<strong>「去年やってた値下げが、比較対象から外れた」</strong>ってこと。

{{< hukidashi who="aashi" >}}え、待って。値下げが外れたら物価が上がるの？？意味わかんないんだけど🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}消費者物価指数の前年同月比は、<strong>今月の水準を1年前の同じ月の水準と比べた変化率</strong>であります。したがって比較される側、すなわち<strong>1年前の水準が低い</strong>と、今月が横ばいでも伸び率は大きく出る構造になります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}あ〜〜〜！去年が安すぎたから、今年が普通でも「上がった」ってカウントされちゃうってこと？？😳{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}概ねその通りでございます。東京都は<strong>2025年9月から第1子の保育料を無償化</strong>しており、<strong>2026年4月からは年度を通じて無料</strong>となっております。また<strong>夏季の水道基本料金の無償化</strong>も実施されましたが、2025年は6月から9月、2026年は5月から8月と、<strong>1ヶ月早まっております</strong>。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}つまり<strong>9月は「去年＝水道代タダ／今年＝普通に請求」</strong>って比較になるんだ💧　去年が0円なんだから、普通の料金に戻っただけで「値上げ」扱いになるじゃん😂{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}ご明察です。発表前の試算では、<strong>保育料と水道料金のこの2項目だけでコアCPIを約0.55ポイント押し上げる</strong>と見込まれておりました。市場の予想は<strong>約2.4%</strong>であり、実績の2.7%はこれを上回っております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}ってことは、政策要因で0.55ポイントぶん自動的に上がる前提だったのに、それより更に上だったのね…つまり<strong>「全部が見せかけ」ってわけでもない</strong>のか🥹{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}そのような整理になります。政策要因の剥落で押し上げられた部分と、それ以外の値上がり圧力の双方が含まれている、と考えております。{{< /hukidashi >}}

ここ、めちゃくちゃ大事なのでもう一回まとめるね📝

伝わる？ <strong>統計の数字は「今月どうなったか」だけじゃなく「去年がどうだったか」でも動く</strong>のよ📊

だから<strong>「2.7%！物価ヤバい！」で終わらせると、半分くらい読み間違える</strong>の。逆に「全部見せかけじゃん」って言い切るのも違う。どっちも入ってるのが正解🙌

## そもそも「コア」と「コアコア」って<span class="mk">何なん</span>？🧐

さっきから「コア」とか「コアコア」とか出てきたけど、これ何？ってなるよね。あーしも最初ふざけた名前だと思ってた😂

{{< hukidashi who="aashi" >}}コアとコアコアって何が違うの？？名前が可愛いだけで意味わかんない🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}いずれも消費者物価指数の<strong>内訳区分</strong>であります。<strong>総合</strong>は全品目を含む指数、<strong>コア（生鮮食品を除く総合）</strong>は生鮮食品を除いた指数、<strong>コアコア（生鮮食品及びエネルギーを除く総合）</strong>は生鮮食品に加えエネルギーも除いた指数を指します。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}なんで生鮮食品だけ仲間外れにされてるの？野菜もお魚もめっちゃ生活費じゃん🥬🐟{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}生鮮食品の価格は<strong>天候や漁獲量の影響で短期的に大きく変動いたします</strong>。そのため、これを含めた指数では<strong>物価全体の基調的な動き</strong>が見えにくくなる、という整理であります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}あ〜なるほど！<strong>台風で白菜が爆上がりした月</strong>があったとして、それって「物価が上がった」とは違うもんね🌀　来月には戻るやつだし{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}その通りでございます。エネルギーも原油価格や補助金によって変動が大きい項目です。これを更に除いたコアコアは、<strong>国内の人件費やサービス価格など、基調的な物価の動き</strong>を見るために用いられます。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}てことは<strong>コアコアが3.0%</strong>って、天候も原油も関係ないところで3%上がってるってこと…？それ地味に重くない？😨{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}コアコアは生鮮食品及びエネルギーを除いた指数であり、今回3.0%の上昇となっております。なお、こちらにも先述の政策要因の影響が含まれる点にはご留意いただきたく存じます。{{< /hukidashi >}}

ニュースで「物価が◯%上がった」って聞いたとき、<strong>どの指数の話なのかで数字が変わる</strong>のよ。今回は総合2.7%／コア2.7%／コアコア3.0%。全部ちょっと違う🧾

## 日銀の2%目標とは<span class="mk">どう関係</span>するの？💴

日銀の物価目標は<strong>2%</strong>。今回のコアCPIは2.7%だから、数字だけ見れば目標を上回ってる状態なの。

日銀は物価の上振れリスクを抑えるために、<a href="/posts/nichigin-125pct-rishage-2026/">政策金利を1.25%まで上げた話</a>があったよね💴 31年ぶりの高さで、3ヶ月で2回は過去最速ペースだったやつ。

で、ここで<strong>「じゃあ次も利上げじゃん」って早合点しないほうがいい</strong>と思うのよ。

<div class="insight">
  <span class="insight-tag">💎 ぶっちゃけポイント</span>
  <p>今回の2.7%は、<em class="kw">政策要因の剥落で押し上げられた面</em>があるの。保育料と水道代の「前年の裏」で約0.55ポイントぶん自動的に乗ってる数字なのよ💧<br><br>日銀が見てるのは<strong>一時的な要因を除いた基調的な物価</strong>だから、<strong>「2.7%出た＝即利上げ」とは言い切れない</strong>の。逆に「全部見せかけだから何もしない」とも言えない。予想の2.4%を上回ってる部分は、政策要因じゃない値上がり圧力だから。<br><br>つまり<strong>どう判断するかは日銀にしか分からない</strong>のよね。あーしたちができるのは<strong>「この数字はどういう中身なのか」を把握しておくこと</strong>だと思う。中身を知らずに見出しだけ追うと、翌月に数字がガクッと下がったとき「え、物価下がったの？」って混乱するだけだから📊</p>
</div>

ちなみに物価と金利の話は<a href="/posts/ai-juyou-bukka-nichigin-2026/">AI需要が物価も日銀の利上げも動かしてる話</a>でも書いたよ🤖 住宅ローンまで繋がってるやつ。

## 2.7%が10年続いたら<span class="mk">どうなる</span>？🧮

⚠️ ここ念押しなんだけど、これ<strong>「もしこのペースが続いたら」っていう仮定の話</strong>だからね。来年の物価が何%になるかは誰にも分からないし、政策要因が剥落しきったら伸び率が落ちることもある。あくまで<strong>「複利ってこういう効き方をするんだよ」っていう体感用の計算</strong>よ🧮

で、仮定の話だとしても<strong>怖いのは「給料が同じペースで上がるか」</strong>なのよ。

物の値段が10年で3割上がって、お給料が10年で3割上がったなら、生活はトントン。でも<strong>お給料が変わらなかったら、実質的に3割貧しくなる</strong>のと同じなの😱

だから物価のニュースを見るときは、<strong>賃上げのニュースとセットで見る</strong>のが大事なのよ💪 片方だけ見てると「物価ヤバい」か「賃上げ嬉しい」のどっちかに偏っちゃう。

## 希望の話も<span class="mk">置いていく</span>ね🍙

暗い話ばっかりで終わりたくないので、決まってる明るいやつも書くね。

<strong>2027年4月から、食料品の消費税が8%→1%になる</strong>の🍙✨ しかも<a href="/posts/rinji-kokkai-21houan-2026/">臨時国会に法案が提出された話</a>のとおり、もう国会の土俵に上がってるのよ。

<a href="/posts/shokuhin-shouhizei-kakugi-kettei-2026/">食品消費税1%が正式に閣議決定された話</a>も書いたけど、財源は「赤字国債に頼らない」って明記されてる。2年間の時限措置っていう形ね📋

食品は<strong>毎日買うもの</strong>だから、税率が7ポイント下がるのは体感デカいと思うの。物価が2.7%上がってるタイミングで食品の税が下がるって、効き方としてはかなり大きいはず🍙

今回いちばん勉強になったのは、<strong>統計の数字は「比較する相手」でも動く</strong>ってことだった📊

去年ほんとにありがたかった保育料の無償化と水道代の無償化。あれが1年たって、今年の数字を押し上げる方向に働いてるって、なんか不思議じゃない？ 支援そのものは良いことなのに、統計の見え方だけが振り回されるのよ💧

だから<strong>見出しの数字だけで怒ったり安心したりしない</strong>。これ、物価のニュースに限らず全部そうだなって思った🙌

とはいえ値上げが続いてるのは本当だから、<strong>そこは怒っていいところ</strong>よ😤 来年4月の食品消費税1%、ちゃんと予定どおり来てほしいわ🍙✨
