<a href="/posts/beikoku-jagaimo-yunyu-kaikin-2026/">先週、米国産ジャガイモの輸入解禁の動きについて書いた記事</a>、けっこう反響あったのよ🥔 で、そのあとちゃんと調べ直したら、思ってたより手続きが具体的なところまで来てて、しかも<strong>「これ外交カードになってない？」</strong>っていう指摘まで出てきてたの😳

今日はその続き。数字と手順のところをちゃんと押さえていくね📋

## 8月28日に<span class="mk">何が決まった</span>の？🔬

農水省がやったのは<strong>リスク評価</strong>。つまり「米国産の生のジャガイモを入れると、どんな病害虫が一緒に来ちゃう可能性があるか」を洗い出す作業なの🐛

その結果、米側と検疫協議が必要な病害虫として<strong>21種</strong>が特定されたのよ。

ここ、ちょっとややこしいから霞ちゃんに整理してもらお📋

{{< hukidashi who="kasumi" >}}輸入解禁の手続きは三つの段階に分かれております。第一に解禁要請の受理、第二に病害虫リスク評価の実施、第三に管理措置および解禁条件の協議であります。今般の病害虫の特定は、第二段階の完了を意味するものと整理されます。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え、じゃあもう3分の2終わってるってこと？？😱{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}手続の段階としてはその通りでありますが、残る第三段階は最も実務的な調整を要する部分でございます。解禁の時期につきましては、なお数年を要する見込みであります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}なるほど、<strong>「ラスボスが一番長い」</strong>タイプのやつね🥔⚔️{{< /hukidashi >}}

## なんで日本は<span class="mk">簡単に断れない</span>の？🌍

「危ないなら断ればいいじゃん」って思うじゃん？ でもそれができない理由があるの。

{{< hukidashi who="kasumi" >}}日本はWTO（世界貿易機関）の加盟国であります。加盟国は、他の加盟国から輸入解禁の要請を受けた場合、原則として科学的な根拠を示さずにこれを拒否することはできないとされております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}つまり「なんとなくヤバそうだから却下」は通らないってこと？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}左様でございます。したがいまして、リスク評価により病害虫を特定し、科学的知見に基づいて必要な管理措置を求めるという手順が不可欠となります。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}あ〜だから21種のリストを作ってたのか。<strong>「感情」じゃなくて「証拠」で戦うルール</strong>なのね🔬{{< /hukidashi >}}

だから農水省がやってる作業って、実は<strong>日本が主張できる材料を集める作業</strong>でもあるのよ📋 ここを雑にやると「科学的根拠がない」って言われて押し切られちゃうの😤

## 21種の中にいる<span class="mk">やばいやつ</span>🐛

特定された21種の中に、<strong>ジャガイモシロシストセンチュウ</strong>っていう線虫がいるの。

これがなんでヤバいかっていうと、<strong>すでに日本にいる</strong>から。2015年に<strong>北海道網走市で国内初確認</strong>されて、いまも産地に影響が続いてるのよ😰

ここが厄介なところで、安さって<strong>あとから戻せる</strong>けど、畑に入っちゃった虫は<strong>あとから戻せない</strong>のよ💀 この非対称さが、産地が慎重になる一番の理由なの。

しかもジャガイモって、あーしらの生活にガチで近いのよ。<a href="/posts/food-neage-june-2026/">6月にじゃがビーが280円→370円に値上げされた記事</a>を書いたときも、原因のひとつがじゃがいもの調達コスト上昇だったし🍟 <a href="/posts/komugi-uriwatashi-12percent-2026/">小麦の政府売り渡し価格が上がった話</a>と同じで、原料のところで起きたことって最後は棚の値札に出てくるの📈

## 「アメリカの防疫が<span class="mk">ゆるい</span>」って話じゃない⚖️

たまに「アメリカの検疫はザルだから危ない」みたいな言われ方するんだけど、これは正確じゃないの🤔

アメリカ側にもちゃんと規制はあるのよ。問題はそこじゃなくて、<strong>どこまでの条件なら日本が受け入れられるかという線引き</strong>のほう。最終段階の協議って、まさにこの線引きを決める作業なの⚖️

だから「アメリカ＝悪」みたいな話にすると論点がズレちゃう。見るべきは<strong>どんな条件が付いたか</strong>で、条件が緩ければ心配だし、厳しければリスクはかなり抑えられる、っていうシンプルな話なのよ👀

## 「外交カード」って<span class="mk">言われてる</span>件♠️

で、ここからが今回いちばん引っかかったところ。

報道では、この解禁協議が<strong>関税交渉の取引材料として扱われてるんじゃないか</strong>という指摘が出てるの😳 つまり「日本がジャガイモを開けるかわりに、別のところでアメリカから譲歩を引き出す」っていう構図ね。

<a href="/posts/nichibei-beichu-shunou-week-2026/">先週の首脳会談ウィークの記事</a>でも書いたけど、いまの日米って関税とかAIとか、いろんなテーマが同時に乗っかってる状態なのよ🇯🇵🇺🇸 その机の上にジャガイモも置かれてる、って見られてるってこと。

新聞の社説では、<strong>食の安全や国内農業の根幹に関わる防疫の問題を政治・外交上の駆け引きだけで決めるのは適切ではない</strong>、<strong>科学的な検証に基づいて厳格に判断すべきだ</strong>、という趣旨の主張も書かれてるの🔬 めっちゃ真っ当だと思うのよね。

政府のほうは、産地の不安に配慮しながら協議すると説明してる、っていう状況📋
