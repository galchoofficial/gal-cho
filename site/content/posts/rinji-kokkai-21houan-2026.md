## もう1本の注目法案、<span class="mk">原油</span>の調達多角化🛢️

消費税のかげで見落とされがちだけど、こっちもガチで重要なのよ。

経済産業省が出すのは、原油の供給体制を強化する<strong>「原油等調達多角化法」</strong>を柱にした法案。<a href="/posts/genyu-saudi-pipeline-2026/">サウジで原油が急騰して中東リスクが意識された流れ</a>を受けたものなのよ。

<div class="gov-block">

  <div class="gov-row">

    <div class="gov-text">事業者がホルムズ海峡への依存度を下げる<strong>調達計画</strong>を出して、国が必要なコストを交付金で支える仕組み💰</div>

なんでこれが大事かっていうと、日本は石油のほとんどを中東から買ってるから。資源エネルギー庁の資料だと、原油の<strong>中東依存度は9割超</strong>で、しかもほぼ全量がホルムズ海峡を通ってくるのよ😱

{{< hukidashi who="aashi" >}}え、ルートが1本しかないってこと？？そこで何か起きたら終わりじゃん🥹{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}資源エネルギー庁の公表資料では、原油の中東依存度は9割を超え、ホルムズ海峡への依存度も同水準と示されています。備蓄は確保されておりますが、恒久的な解決にはならないと整理されています。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}つまり「備蓄で時間は稼げるけど、仕入れ先を増やさないと根本は変わらない」ってこと？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}ご明察です。今回の法案は、その調達先の分散を政策として支える枠組みと承知しております。{{< /hukidashi >}}

値上げラッシュの元をたどると、だいたいここに行き着くのよ。食品の値上げも電気代もガソリンも、中東リスクと円安が根っこにあるから🛢️💸

## <span class="mk">法案提出＝成立</span>じゃないのよ📋

ここ、ガチで大事。「法案が出た」って聞くと決まった気がするけど、全然まだなの。

{{< hukidashi who="aashi" >}}法案って出したらそのまま法律になるんじゃないの？？🤔{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}なりません。内閣が提出した法案は、まず一方の議院に送られ、関係する委員会で審査された上で本会議において議決されます。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}委員会が先で、本会議が後なんだ。委員会って何してるの？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}専門の委員が条文の内容や影響を質疑する場であります。修正が行われることもございます。本会議で可決されますと、もう一方の議院に送られ、同様に委員会と本会議の審査を経ます。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}え、同じ流れを2回やるの？？衆議院で通っても、参議院でまた委員会→本会議ってこと？{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}その通りでございます。両議院で可決されて初めて法律となります。したがって、提出の時点では成立は確定していないと認識しております。{{< /hukidashi >}}

{{< hukidashi who="aashi" >}}つまり「出た」はスタートラインで、ゴールは12月12日の会期末までのどこか…ってことね🏛️⏰{{< /hukidashi >}}

{{< hukidashi who="kasumi" >}}概ねその通りであります。会期内に議決に至らない場合の扱いも制度上定められております。{{< /hukidashi >}}

つまり、ここから69日間ずっと見張らなきゃいけないってこと。あーしのじゃがビー代の行方がかかってるのよ🍟
