## 編集方針

リコールや制度変更、面白い国会答弁、復興エピソード、アニメ・ゲーム情報まで、**知ったら誰かに話したくなるネタ** を集めて、20〜30代向けに「サクッと読める形」でお届けします。

### 4本柱

- 🛡 **ためになる系** — 注意喚起・リコール・詐欺警告・制度変更
- 💅 **面白い系** — 意外な制度・答弁解説・知的好奇心ネタ
- 😭 **エモい系** — 復興・挑戦・動物・季節・地域
- 🎮 **アニメ・ゲーム系** — 新作発表・業界ニュース・コラボ・ランキング

### 編集ポリシー

- 元ネタの事実情報を使い、独自の切り口でリライト
- 政治の対立・党派批判には踏み込まない
- 個人攻撃・差別・デマは絶対に扱わない
- 健康情報は公的機関ソースに基づいたもののみ
- 事件・事故は防犯・安全情報の文脈でのみ扱う

## 編集体制とE-E-A-T

**ギャル庁** は架空のキャラクター「あーし」が解説する形式ですが、記事制作は以下の体制で行っています。

### 編集フロー

1. **情報収集**：複数の公的機関・主要報道機関（NHK・朝日新聞・読売新聞・日本経済新聞・産経新聞・毎日新聞 等）の一次情報を照合
2. **事実確認**：日付・数値・引用は最低2ソース以上で裏取り
3. **執筆**：「あーし」のトーンでリライトしつつ、要点・出典・根拠を明示
4. **公開前チェック**：誤情報・差別表現・著作権侵害の有無を確認
5. **公開後**：誤りが見つかった場合は速やかに記事を修正、必要に応じて訂正履歴を明記

### 主な参照情報源

| 分野 | 主な参照先 |
|---|---|
| **政治・行政** | 各省庁公式サイト（首相官邸・厚労省・国交省 等）／NHK NEWS WEB／朝日新聞デジタル／読売新聞オンライン |
| **経済・金融** | 日本銀行公式／金融庁公式／日本経済新聞／ロイター日本版 |
| **防災・気象** | 気象庁公式／消防庁公式／内閣府防災情報 |
| **医療・健康** | 厚生労働省公式／PMDA／公的医療機関の公式情報 |
| **アニメ・ゲーム** | ファミ通／電撃オンライン／4Gamer.net／アニメ！アニメ！／コミックナタリー |
| **スポーツ** | スポニチ／サンスポ／FIFA公式 等 |
| **法律・制度** | e-Gov 法令検索／衆議院・参議院公式 |

### 記事修正・訂正ポリシー

- 事実誤認・数値の誤り：判明次第、本文を修正し記事末尾に訂正履歴を明記
- 情勢変化（法案成立・統計更新等）：続報記事を別途公開し、元記事から相互リンク
- 差別的・不適切な表現：即時修正
- 読者からの指摘：[お問い合わせ](/contact/) より受付（メールで返信）

### 取り扱わないテーマ

E-E-A-T（経験・専門性・権威性・信頼性）の観点から、以下のテーマは扱いません：

- **特定の医薬品・サプリ・治療法の効能の断定**（医師でないため）
- **個別株・FX・暗号資産の投資推奨**（金融商品取引業ではないため）
- **特定政党・宗教団体への支持・批判**（政治的中立性のため）
- **未確認情報・噂・陰謀論**
- **個人攻撃・誹謗中傷・名誉毀損につながる内容**

### 広告・アフィリエイトの方針

- 記事内のアフィリエイトリンクは、記事内容と関連性が高い商品のみ掲載
- ユーザーに不利益となる「煽り」や「過度な購買誘導」は行わない
- 詳細は [プライバシーポリシー](/privacy/) の「アフィリエイトプログラムについて」をご確認ください
