# ギャル庁 編集方針（競合分析 + ペルソナ定義）

最終更新: 2026年5月7日

---

## 🎯 ターゲットペルソナ

### メイン読者像

#### ペルソナA: 「**X依存ぎみの若手OL** あゆみ（27歳）」← 軸

- 都内勤務、推し活ガチ勢
- X を1日5回以上開く、TLを流し見
- ニュース番組は見ない、Yahoo!ニュースのタイトル読みだけ
- 制度や政治には興味あるけど **「難しい言葉が出てきた瞬間に閉じる**」
- 友達と LINE で「これマジ？？」って共有する
- 共感とユーモアに弱い、説教には反発

**この人が「あ、これあーしと同じこと考えてた！」って思ったら勝ち。**

#### ペルソナB: 「**就活中の理系大学生** ゆうき（21歳）」

- 親に「ニュース見ろ」と言われるけど、堅い番組は無理
- 制度・税金がマジでわからん（けど人生に直結する）
- まとめサイト世代だけど、ヤフコメや 5ch のノリは合わない
- ギャル文体 = ふざけてる、じゃなくて **「読みやすいから読む」**
- TikTok や YouTube の解説系も見る

**この人にとって「教科書代わり」になるのが理想。**

#### ペルソナC: 「**世帯持ち30代パパ** たかし（34歳）」

- 妻が読みそう、子どもが読みそう、と思って LINE 共有してくる
- 自分は読まないけど、家族の話題のネタにする
- 「これ俺もちゃんと知らなきゃ」って気持ちもある

**この人が共有したくなる「家族トピック」を意識する。**

---

### ターゲット外（読まれなくていい層）

- 5ch まとめのノリが好きな男性中心読者（暇人速報・痛いニュース系）
- 完全な政治マニア（ニュースサイトをハシゴしてる人）
- 「ギャル語が嫌い」と感じる読み手
- 中高年の保守層

→ **彼らに媚びると、メイン3層の読者がノリと違和感を持って離れる**。
→ 読者層は意図的に絞る。

## ✋ ギャル庁フィルター（競合の真似をする前のチェック）

何かを取り入れる前に、必ず4つチェックする:

### Q1. **あーしが言いそう？**
JK17歳・渋谷系オタク・推し活系の女の子が、本当に口にする言葉？  
→ NO なら **不採用** か **ギャル化アレンジ** が必要。

### Q2. **ペルソナA（あゆみ27歳）が「わかる〜」って言う？**
彼女がスクロール中に止まって、共感する？読みたくなる？  
→ NO なら **角度を変える**。

### Q3. **誰かを傷つけてない？**
特定個人・職業・属性・ジェンダーをディスってない？  
→ YES なら **絶対不採用**。

### Q4. **ブログを長く続けるための行動か？**
短期バズ狙いの煽り・釣り・倫理スレスレ ではない？  
→ 「3ヶ月後に振り返って恥ずかしくない」基準で判定。

## 📋 競合から学んだ7つの型 → ギャル庁での実装ルール

### ① 「→」記号でストーリー圧縮

**OKパターン**:
```
GW明け→クラスがガラガラだったの思い出した
奨学金提案→政府「ダメです」のツッコミ4選
```

**NG（避ける）**:
```
美女→衝撃の素顔   ← 外見フック、品下がる
〇〇社員→失踪してた   ← 個人特定/ゴシップ
```

### ② 引用符「」で他者の声

**OKパターン**:
```
石垣ちゃん「奨学金もOKにして？」
総理「仮定の質問にはお答えしません」
```

**NG**:
```
「あの女優、整形バレた」   ← ゴシップ
「俺の彼女が浮気で…」   ← 私生活詮索
```

### ③ 数字の具体性
- 既に得意。維持。
- 「1329万人」「559品目」「280億円」など継続。

### ④ 「Xつ・X選」リスト記事
- 月1〜2本ペース推奨
- ペルソナBが保存しやすい構造
- ただし **「この5選が選ばれた理由」が薄いとつまらない** → 必ず根拠を入れる
- ✅ 既存「5月病予防5つの対策」◎
- 🔥 ネタ案: 「令和8年に変わった制度5選」「親に説明できない税金用語7つ」

### ⑤ キーワードハイライト
- タイトルでは記号で `「」` `""` を使う
- 本文中では `<mark>` ハイライトを継続使用 ◎

### ⑥ ジャンル多様化（特にエモい系）
- 現状: tame多すぎ・emo少なすぎ
- 投稿時間帯バランス:
  - 朝: ためになる
  - 昼: 面白い
  - 夜: エモい / アニメ
- エモい系の鉄板素材:
  - 保護動物 / 地域美談 / 復興 / 個人の挑戦
  - 季節モノ（梅雨入り、夏祭り、秋の収穫など）

### ⑦ 避けるべき低品質フック ❌
- 外見・性的フック
- 政治的対立を煽る
- 個人攻撃・私生活詮索
- 不安だけ煽って結論ない
- 過度な hyperbole（「人類滅亡レベル」とか嘘くさい）

## 📐 タイトル付けの黄金フォーマット

ギャル庁オリジナルとして、以下を組み合わせる:

```
[フック1行] + [→で展開] + [絵文字] + [語尾の問いかけ/感想]
```

**例**:
```
GW明けで死にかけた→5月病にならない準備5選🥲✨
信用組合で280億円→25人減給で結局どうなった？🏦
奨学金返済きつい？→政府ツッコミ4選で泣ける💸
```

語尾には常に **「〜じゃん？」「〜なのよね」「〜って知ってた？」** どれかを入れて、あーしの声をブレさせない。

## 🚦 NG ネタ・グレー判断ルール（再確認）

これは [企画書](2026年5月3日_gal_news_blog_plan.md) の方針を踏襲:

### NG（絶対書かない）
- 政治の対立・政党批判
- 芸能ゴシップ・不倫・スキャンダル
- 個人攻撃・炎上便乗
- 宗教・差別に関わるもの
- デマ・未確認情報
- 死亡事故・災害の犠牲者・慰霊系（防災情報なら可）

### グレーゾーン（慎重判断）
- 企業の不祥事 → 消費者目線の注意喚起ならOK
- 事件・事故 → 防犯・安全情報なら可
- 健康情報 → 公的ソースありなら可
- アニメ・ゲーム → ニュースとしてなら可、ネタバレ・転載NG

### 優先度を下げるテーマ
- お金・投資系（NISA、株、投資信託など）→ 月1〜2本目安
- 「投資詐欺」の注意喚起は別枠でOK
