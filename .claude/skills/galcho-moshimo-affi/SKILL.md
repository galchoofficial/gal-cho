# ギャル庁 もしもアフィリエイト取得スキル

ギャル庁の記事に「かんたんリンク」を貼る時に呼ぶ。

## 🚨 絶対禁止（最優先）

### スニペット捏造禁止
- もしもUIを経由しない**ニセスニペットを絶対に作らない**
- 楽天検索URL（`search.rakuten.co.jp`）+ 適当な eid を組み合わせて作るのは**完全な偽物・厳禁**
- 「商品名」だけ書いて画像なし・c_p なし・p空配列のスニペットも**完全な偽物**
- サブエージェントにも「アフィスニペットは入れない・placeholder だけ」と明示

### 必ず守る
- スニペットは**必ずもしもUI経由**で取得（JS DOM 操作 or 「全文コピー」ボタン）
- 商品URL、c_p、p配列、eid、すべて**もしも本物の値**を使う

## 🚫 ジャンル禁止リスト

以下は**絶対にアフィに使わない**:
- ❌ FX関連書籍（「○○で稼ぐ」「うまい方法」「トレンドラインで稼ぐ」）
- ❌ 投資勧誘・投資指南書（個別株推奨・投資手法本）
- ❌ ギャンブル系（パチンコ攻略・カジノ攻略）
- ❌ 情報商材（高額情報販売）
- ❌ 健康詐欺寄り商品（科学的根拠の薄い健康食品・痩身グッズ）
- ❌ 金融商品取引業に近いもの

### OKジャンル
- ✅ 経済・金融の**入門書 / 解説書 / 学者の評論本**（マンガでわかる系・池上彰系）
- ✅ 児童書・教育書（10歳からのシリーズ等）
- ✅ 書籍全般（小説・漫画・写真集）
- ✅ ゲーム・グッズ・キャラクター商品
- ✅ 電化製品・日用品（PSE等認証あれば◎）
- ✅ ふるさと納税（楽天ふるさと納税）

### 検索キーワードのコツ
- ❌ 「FX」「投資」「稼ぐ」「副業」「攻略」を入れない
- ✅ 代わりに「マンガでわかる○○」「子ども向け○○」「入門」「池上彰」「新書」

## 🔧 JS DOM 操作の正解パターン（2026-05-31 確立）

### なぜ JS 操作か
- 座標クリックだとタブがフリーズすることが多い
- もしもUI内部で jQuery delegate event が使われているので、**MouseEvent シリーズの dispatch** が必要
- 一度フリーズしたらタブを閉じて新規タブで開き直すのが最速

### Step 1: 検索フォーム発火

```js
// もしも管理画面に form が2つある：
// form[0] = プロモーション検索（promotion_search_form, action=/promotion/search）
// form[1] = かんたんリンク（action=/easy-link-card） ← こっち使う
const form = document.querySelectorAll('form')[1];
form.querySelector('input').value = '検索キーワード';
form.parentElement.querySelector('a.button').click();
```

- 結果ロードは 5〜10秒かかる（焦らない）
- 検索結果が空に見えても追加で5秒以上待つ

### Step 2: 商品クリック（jQuery delegate event 対応）

```js
const ul = document.querySelector('ul.result');
const targetLi = ul.querySelectorAll('li')[idx];  // idx は 0 始まりの商品番号
[targetLi, ...targetLi.querySelectorAll('*')].forEach(el => {
  el.dispatchEvent(new MouseEvent('mousedown', {bubbles:true}));
  el.dispatchEvent(new MouseEvent('mouseup', {bubbles:true}));
  el.dispatchEvent(new MouseEvent('click', {bubbles:true}));
});
```

- **画像エリア相当をクリック**（テキストクリック相当は別タブで楽天が開いてしまう）
- LI 本体だけだとイベントが発火しないことがあるので**全子要素にも dispatch**

### Step 3: スニペット抽出

```js
const ta = [...document.querySelectorAll('textarea')].find(t => t.value && t.value.length > 200);
// ta.value がスニペットHTML
console.log(ta.value);
```

- HTMLソース欄の textarea を最大長で特定（プレビュー欄の textarea もあるので length > 200 で絞る）
- 取得後そのまま記事の `<!-- AFFI: -->` プレースホルダに置換

## 🔍 検索キーワードのコツ

- **短め・単純な単語**が確実にヒット
  - ❌ `Xbox Series X` → 0件
  - ✅ `Xbox` → ヒット
  - ❌ `モバイルバッテリー` → 自動車用混在
  - ✅ `PowerCore`（ブランド名）→ ピンポイント
- 複合キーワードは1〜2語まで、それ以上は要検証

### 確認済み有効キーワード
`ONE PIECE`, `カービィ ぬいぐるみ`, `Xbox`, `PowerCore`, `ニセコ`, `スキミング防止`, `税金 本`, `確定申告`, `名探偵プリキュア プリキットブック`, `ドラゴンクエストVII Reimagined Switch`, `防災士監修47点セット`, `GLOBAL WORK Tシャツ`

## ⚠️ UI のクセ

### キーワード累積バグ
- 検索結果ページではキーワード「タグ」が累積する
- 新しい検索する前に**前のタグを × で削除**
- 「クリア」ボタンはチェックボックスのみクリア・タグは消えない（罠）

### タブフリーズ
- 商品クリック後にタブが固まったら**閉じて新規タブで開き直す**
- 座標クリックで固まることが多い → JS DOM 操作なら安定

### アカウント確認
- もしもアフィリエイトのアカウントは**ギャル庁のもののみ**
- ログイン中アカウント表示を毎回確認

## 🤝 ブラウザ操作は並列不可

- 同一ブラウザセッションで複数タブを開いて並列操作するのは競合するので**順次のみ**
- アフィ取得は1記事ずつ完了させてから次へ

## 📦 スニペット差し込み手順（記事側）

1. 記事 .md 内の `<!-- AFFI: 商品キーワード -->` を探す
2. もしもUI で取得したスニペット HTML をそのプレースホルダに置換
3. その前後に「あーし的にコレおすすめ💕」みたいな導入文を**ユーザー語り口で**1〜2行追加
4. PR 表記が含まれているか確認（もしもスニペットには通常含まれる）
